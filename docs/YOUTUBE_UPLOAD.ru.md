# Публикация на YouTube

После рецепта «Видео на YouTube» приложение может передать готовый пакет
(название, описание с таймкодами, теги, обложку) в YouTube — вручную или
загрузкой через YouTube Data API. Что включать, выбирается в
**Настройки → ИИ / LM Studio → «После запуска «Видео на YouTube»»**:

| Режим | Что происходит |
|---|---|
| Ничего не делать (по умолчанию) | Ничего не открывается. Кнопка «Опубликовать на YouTube» всё равно есть на экране прогона, во вкладке YouTube и в меню «Файл» / палитре команд. |
| Открыть диалог публикации | После прогона открывается диалог: проверка текста по лимитам YouTube, кнопки «Копировать название / описание / теги», «Показать видео в Finder», «Сохранить пакет в папку», «Открыть YouTube Studio». Приложение ничего не отправляет само. |
| Открыть диалог и разрешить загрузку | То же + кнопка «Загрузить на YouTube»: видео уходит на ваш канал приватным (или «по ссылке»), затем открывается страница редактирования в Studio, где вы проверяете и публикуете его вручную. |

Загрузка идёт только по нажатию кнопки. Название выбирается в диалоге из
сгенерированных вариантов; текст можно править прямо там.

## Подготовка Google Cloud (нужна только для загрузки через API)

Приложение не содержит встроенного ключа: вы создаёте свой OAuth-клиент.

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект
   и включите **YouTube Data API v3**.
2. **OAuth consent screen**: тип *External*; добавьте свой Google-аккаунт в
   *Test users*.
   **Важно:** пока приложение в статусе *Testing*, вход (refresh-токен)
   истекает через 7 дней. Для постоянной работы переведите его в
   *In production*. Для личного использования проверка не обязательна:
   при входе Google покажет «Google hasn't verified this app» — выберите
   *Advanced → Continue*.
3. **Credentials → Create credentials → OAuth client ID**, тип
   **Desktop app**. Скачайте JSON.
4. В приложении: **Настройки → ИИ / LM Studio → Аккаунт YouTube → «Импортировать
   client_secret.json…»**, затем **«Подключить аккаунт»**. Откроется браузер
   для входа; после успеха в настройках появится название канала.
   Отключение («Отключить») отзывает токен и удаляет его из связки ключей.

Токен входа хранится в Keychain (macOS) / Credential Manager (Windows) /
Secret Service (Linux). Если системной связки ключей нет, токен живёт только
до закрытия приложения — подключать аккаунт придётся заново. `client_secret`
хранится там же, а не в `config.json`.

## Ограничения YouTube

- **Проект без аудита.** Видео, загруженные через API проектом Google, который
  не прошёл аудит, YouTube оставляет приватными, пока аудит не пройден
  ([форма запроса](https://support.google.com/youtube/contact/yt_api_form)).
  Публиковать видео всё равно вы будете сами в Studio.
- **Квота API** — ограниченное число единиц в сутки на проект; загрузка видео
  расходует много. Актуальная стоимость — в документации квот YouTube Data API.
  При исчерпании приложение сообщит об этом и ничего не потеряет.
- **Своя обложка** через API ставится только на канале, подтверждённом по
  телефону. Если не получилось, видео всё равно загружено, а приложение
  предупредит, что обложку нужно поставить в Studio.
- **Прерванная загрузка** (отмена, закрытие приложения, обрыв сети) продолжается
  с того же места: при следующем открытии диалога кнопка называется
  «Продолжить загрузку». Сессия загрузки хранится на стороне Google около
  недели.
- **Повторная загрузка** той же записи требует подтверждения — чтобы случайно
  не создать дубль на канале.
- Лимиты: название до 100 символов, описание до 5000 байт, теги до 500 символов
  в сумме, без `<` и `>` в названии и описании. Диалог показывает счётчики и
  предупреждает заранее.
