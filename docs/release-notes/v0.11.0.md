## Whispered v0.11.0

This release closes the loop on the "Video for YouTube" recipe: after a run you
can publish the finished package — title, description with timecodes, tags and
cover — to your own YouTube channel, either by hand-off to YouTube Studio or by
uploading the video through the YouTube Data API. The YouTube tab was reworked
into an editor for the generated package.

### Downloads

| Platform | File | Notes |
|---|---|---|
| macOS (Apple Silicon) | `Whispered-v0.11.0-macos-arm64.zip` | macOS 13+; unsigned — see below |
| Windows 11 (x64) | `Whispered-v0.11.0-windows-x64.zip` | unsigned preview — see below |

Verify your download against `SHA256SUMS.txt`:

```bash
shasum -a 256 -c SHA256SUMS.txt      # macOS / Linux
```
```powershell
(Get-FileHash Whispered-v0.11.0-windows-x64.zip -Algorithm SHA256).Hash
```

### Highlights

- **Publish to YouTube** — a dialog after the YouTube recipe (opt-in, Settings →
  AI / LM Studio): limits checked up front (title, description bytes, tags),
  copy buttons, reveal the video in Finder, save the package to a folder, open
  YouTube Studio.
- **Upload through the YouTube Data API (optional, off by default)** — your own
  Google Cloud OAuth client, resumable upload with resume after interruption,
  cover upload, private/unlisted visibility, duplicate-upload guard. The video
  leaves your machine only when you press the button. Setup:
  `docs/YOUTUBE_UPLOAD.ru.md`.
- **YouTube tab as a step viewer** — edit chapters by hand, seek the player from
  chapters, chapter ticks on the timeline, build the description from blocks,
  pick the title, shift timecodes for a missing intro, run the YouTube step on
  its own.
- Fixes: opening a record always shows its own YouTube package and Insights;
  description labels follow the package's language.

### Known limitations

- Videos uploaded through the API by a Google project that has not passed
  Google's audit stay private until it does; you publish them in Studio.
- Custom covers through the API need a channel verified by phone.
- Four tests in `tests_qt/test_recipe_retry.py` currently fail; not
  user-visible.

### Installing on macOS (unsigned build)

These builds are **not signed with an Apple Developer ID and not notarized**
($99/year Apple Developer Program). Gatekeeper will block the first launch.
This is expected — the app is not doing anything unusual, it simply has no
paid signature.

1. Unzip and move `Whispered.app` to `/Applications`.
2. Right-click `Whispered.app` → **Open** → **Open** in the dialog. (A plain
   double-click only offers "Move to Trash".)
3. If macOS still refuses, run once in Terminal:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

The whisper transcription engine ships **inside** the app — no extra
install step. Model weights download on first use.

### Installing on Windows (unsigned preview)

No code-signing certificate yet, so SmartScreen shows
"Windows protected your PC". Click **More info** → **Run anyway**. Unzip
anywhere and run `Whispered.exe`.

## Whispered v0.11.0 (Русский)

Релиз замыкает рецепт «Видео на YouTube»: после прогона готовый пакет —
название, описание с таймкодами, теги и обложку — можно опубликовать на свой
канал YouTube: передать в YouTube Studio вручную или загрузить видео через
YouTube Data API. Вкладка YouTube переработана в редактор сгенерированного
пакета.

### Загрузки

| Платформа | Файл | Примечания |
|---|---|---|
| macOS (Apple Silicon) | `Whispered-v0.11.0-macos-arm64.zip` | macOS 13+; без подписи — см. ниже |
| Windows 11 (x64) | `Whispered-v0.11.0-windows-x64.zip` | превью без подписи — см. ниже |

Проверьте загрузку по `SHA256SUMS.txt`:

```bash
shasum -a 256 -c SHA256SUMS.txt      # macOS / Linux
```
```powershell
(Get-FileHash Whispered-v0.11.0-windows-x64.zip -Algorithm SHA256).Hash
```

### Главное

- **Публикация на YouTube** — диалог после YouTube-рецепта (включается в
  Настройки → ИИ / LM Studio): проверка лимитов (название, байты описания,
  теги), кнопки копирования, показать видео в Finder, сохранить пакет в
  папку, открыть YouTube Studio.
- **Загрузка через YouTube Data API (опционально, по умолчанию выключена)** —
  ваш собственный OAuth-клиент Google Cloud, докачка после обрыва, загрузка
  обложки, приватное/«по ссылке», защита от повторной загрузки. Видео уходит с
  компьютера только по нажатию кнопки. Настройка: `docs/YOUTUBE_UPLOAD.ru.md`.
- **Вкладка YouTube как просмотр шага** — ручная правка глав, перемотка плеера
  по главам, засечки глав на таймлайне, описание из блоков, выбор названия,
  сдвиг таймкодов при отсутствующем интро, отдельный запуск YouTube-шага.
- Исправления: открытая запись всегда показывает свой YouTube-пакет и свои
  Инсайты; подписи в описании следуют языку пакета.

### Известные ограничения

- Видео, загруженные через API проектом Google, не прошедшим аудит, остаются
  приватными до его прохождения; публикуете вы их сами в Studio.
- Своя обложка через API требует канала, подтверждённого по телефону.
- Четыре теста в `tests_qt/test_recipe_retry.py` сейчас падают; для
  пользователя это не заметно.

### Установка на macOS (сборка без подписи)

Сборки **не подписаны Apple Developer ID и не нотаризованы** (программа
Apple Developer — $99/год). При первом запуске Gatekeeper заблокирует
приложение. Это ожидаемо: приложение не делает ничего необычного, просто
у него нет платной подписи.

1. Распакуйте и переместите `Whispered.app` в `/Applications`.
2. Правый клик по `Whispered.app` → **Открыть** → **Открыть** в диалоге.
   (Обычный двойной клик предложит только «Переместить в корзину».)
3. Если macOS всё ещё не пускает, один раз выполните в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

Движок транскрипции whisper поставляется **внутри** приложения — отдельная
установка не нужна. Веса моделей скачиваются при первом использовании.

### Установка на Windows (превью без подписи)

Сертификата подписи кода пока нет, поэтому SmartScreen покажет
«Система Windows защитила ваш компьютер». Нажмите **Подробнее** →
**Выполнить в любом случае**. Распакуйте архив и запустите `Whispered.exe`.
