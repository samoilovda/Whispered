## Whispered v0.14.0

A redesigned interface and a bigger toolbox: proofreading, task cards,
subtitles, collections, project export/import, local AI profiles and a
short-clips pilot, plus an inline transcript editor and a waveform player.

### Downloads

| Platform | File | Notes |
|---|---|---|
| macOS (Apple Silicon) | `Whispered-v0.14.0-macos-arm64.zip` | macOS 13+; unsigned — see below |
| Windows 11 (x64) | `Whispered-v0.14.0-windows-x64.zip` | unsigned preview — see below |
| Linux (x86_64, Fedora) | `Whispered-v0.14.0-linux-x86_64.tar.gz` | preview, microphone-only Live — see below |

Verify your download against `SHA256SUMS.txt`:

```bash
shasum -a 256 -c SHA256SUMS.txt      # macOS / Linux
```
```powershell
(Get-FileHash Whispered-v0.14.0-windows-x64.zip -Algorithm SHA256).Hash
```

### Highlights

- **New look** — refreshed surfaces and start screen, a `Ctrl+K` palette with
  icons and shortcut keycaps, a waveform player with the cut shown on it, and
  an inline transcript editor (one line per segment, Save / Cancel).
- **Proofreading mode** and **task cards** — review a transcript's uncertain
  passages; turn Insights into reviewable tasks.
- **Subtitles** — a Subtitles tab cuts the transcript into cues within
  editable reading limits; fix, split, merge, then export SRT / WebVTT.
- **Collections and saved searches** — group records without copying them;
  a search hit shows where the words are said and opens the record there.
- **Project export / import** — File → Export project… packs a record into a
  `*.whispered.zip` with a checksum manifest; import validates the archive
  and never changes existing records.
- **Local AI profiles** — named LM Studio profiles and editable prompt
  templates for every LLM step.
- **Short clips (pilot)** and a **Live presentation window** (behind a flag).
- **Queue** — a stored queue runs each file's recipe, with retries and resume;
  a record's chat, cut and book now belong to the record.

### Known limitations

- Short clips and the Live presentation window are early previews.
- Semantic (embedding) search is not part of collections yet.

### Installing on macOS (unsigned build)

These builds are **not signed with an Apple Developer ID and not notarized**.
Gatekeeper will block the first launch; this is expected.

1. Unzip and move `Whispered.app` to `/Applications`.
2. Right-click `Whispered.app` → **Open** → **Open** in the dialog.
3. If macOS still refuses, run once in Terminal:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

The whisper transcription engine ships **inside** the app. Model weights
download on first use.

### Installing on Windows (unsigned preview)

SmartScreen shows "Windows protected your PC": click **More info** →
**Run anyway**. Unzip anywhere and run `Whispered.exe`.

### Installing on Linux (preview)

```bash
tar xzf Whispered-v0.14.0-linux-x86_64.tar.gz
./Whispered/Whispered
```

It needs `ffmpeg` (`sudo dnf install ffmpeg-free`) and, under X11,
`xcb-util-cursor`. Live records the microphone only.

## Whispered v0.14.0 (Русский)

Обновлённый интерфейс и больше инструментов: вычитка, карточки задач,
субтитры, коллекции, экспорт и импорт проекта, профили локального ИИ и
пилот коротких клипов, а также редактор транскрипта прямо в тексте и плеер с волной.

### Загрузки

| Платформа | Файл | Примечания |
|---|---|---|
| macOS (Apple Silicon) | `Whispered-v0.14.0-macos-arm64.zip` | macOS 13+; без подписи — см. ниже |
| Windows 11 (x64) | `Whispered-v0.14.0-windows-x64.zip` | превью без подписи — см. ниже |
| Linux (x86_64, Fedora) | `Whispered-v0.14.0-linux-x86_64.tar.gz` | превью, Live только с микрофона — см. ниже |

Проверьте загрузку по `SHA256SUMS.txt`:

```bash
shasum -a 256 -c SHA256SUMS.txt      # macOS / Linux
```
```powershell
(Get-FileHash Whispered-v0.14.0-windows-x64.zip -Algorithm SHA256).Hash
```

### Главное

- **Новый вид** — обновлённые поверхности и стартовый экран, палитра `Ctrl+K`
  с иконками и клавишами, плеер с волной и отметкой вырезанного, редактор
  транскрипта прямо в тексте (строка на сегмент, Сохранить / Отмена).
- **Режим вычитки** и **карточки задач** — проверка сомнительных мест
  транскрипта; Инсайты превращаются в задачи для проверки.
- **Субтитры** — вкладка «Субтитры» режет транскрипт на реплики в заданных
  пределах чтения; правка, разделение, склейка и экспорт в SRT / WebVTT.
- **Коллекции и сохранённые поиски** — группировка записей без копирования;
  результат поиска показывает, где сказаны слова, и открывает запись в этом месте.
- **Экспорт / импорт проекта** — Файл → Экспорт проекта… собирает запись в
  `*.whispered.zip` с манифестом контрольных сумм; импорт проверяет архив и
  не меняет существующие записи.
- **Профили локального ИИ** — именованные профили LM Studio и редактируемые
  шаблоны промптов для каждого шага с LLM.
- **Короткие клипы (пилот)** и **окно презентации Live** (за флагом).
- **Очередь** — сохранённая очередь запускает рецепт каждого файла с повторами
  и возобновлением; чат, вырезка и книга теперь принадлежат записи.

### Известные ограничения

- Короткие клипы и окно презентации Live — ранние превью.
- Семантический поиск (по эмбеддингам) в коллекциях пока не входит.

### Установка на macOS (сборка без подписи)

Сборки **не подписаны Apple Developer ID и не нотаризованы**. При первом
запуске Gatekeeper заблокирует приложение — это ожидаемо.

1. Распакуйте и переместите `Whispered.app` в `/Applications`.
2. Правый клик по `Whispered.app` → **Открыть** → **Открыть** в диалоге.
3. Если macOS всё ещё не пускает, один раз выполните в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

Движок whisper поставляется **внутри** приложения. Веса моделей скачиваются
при первом использовании.

### Установка на Windows (превью без подписи)

SmartScreen покажет «Система Windows защитила ваш компьютер»: нажмите
**Подробнее** → **Выполнить в любом случае**. Распакуйте архив и запустите
`Whispered.exe`.

### Установка на Linux (превью)

```bash
tar xzf Whispered-v0.14.0-linux-x86_64.tar.gz
./Whispered/Whispered
```

Нужны `ffmpeg` (`sudo dnf install ffmpeg-free`) и, под X11,
`xcb-util-cursor`. Live записывает только микрофон.
