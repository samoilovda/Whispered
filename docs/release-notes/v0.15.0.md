## Whispered v0.15.0

YouTube uploads without a terminal, clocks that show long LLM work is still
moving, and a cleaner status bar that tells you which LLM and which
transcription model and hardware are in use.

### Downloads

| Platform | File | Notes |
|---|---|---|
| macOS (Apple Silicon) | `Whispered-v0.15.0-macos-arm64.zip` | macOS 13+; unsigned — see below |
| Windows 11 (x64) | `Whispered-v0.15.0-windows-x64.zip` | unsigned preview — see below |
| Linux (x86_64, Fedora) | `Whispered-v0.15.0-linux-x86_64.tar.gz` | preview, microphone-only Live — see below |

Verify your download against `SHA256SUMS.txt`:

```bash
shasum -a 256 -c SHA256SUMS.txt      # macOS / Linux
```
```powershell
(Get-FileHash Whispered-v0.15.0-windows-x64.zip -Algorithm SHA256).Hash
```

### Highlights

- **YouTube upload queue in the app** — File → YouTube upload queue… lists
  the queued packages with each record's state and uploads them (or pushes
  edited titles, descriptions and tags) with progress and cancel. The
  publish wizard's last step gets **Upload now**. The window doesn't block
  the app; closing it keeps the upload going.
- **Progress you can trust** — insights and YouTube package steps report each
  LLM call ("Titles (2 of 6)…"), the status bar shows a ticking elapsed time,
  the recipe run screen's clocks tick every second, and the chat says
  "Thinking… m:ss" until a reasoning model's first word.
- **Redesigned status bar** — flat chips with icons instead of emoji. The LLM
  chip shows the model LM Studio actually has loaded; its popover shows the
  server and lets you switch AI profile or check again. The transcription
  chip ("large-v3-turbo · Metal") picks GPU or CPU. The queue chip appears
  only while something is queued.
- **Publish wizard** — drag and zoom photos inside their frames, and pick a
  photo for the first speaker too.
- **Fixes** — a YouTube login Google rejected is forgotten, so you can sign
  in again without pressing Disconnect first.

### Known limitations

- Short clips and the Live presentation window are still early previews.
- The status bar shows the default transcription model; a recipe with its
  own model uses that one.

### Installing on macOS (unsigned build)

These builds are **not signed with an Apple Developer ID and not notarized**.
Gatekeeper will block the first launch; this is expected.

1. Unzip and move `Whispered.app` to `/Applications`.
2. Right-click `Whispered.app` → **Open** → **Open** in the dialog.
3. If macOS still refuses, run once in Terminal:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

The whisper transcription engine ships **inside** the app. Model weights
download on first use.

### Installing on Windows (unsigned preview)

SmartScreen shows "Windows protected your PC": click **More info** →
**Run anyway**. Unzip anywhere and run `Whispered.exe`.

### Installing on Linux (preview)

```bash
tar xzf Whispered-v0.15.0-linux-x86_64.tar.gz
./Whispered/Whispered
```

It needs `ffmpeg` (`sudo dnf install ffmpeg-free`) and, under X11,
`xcb-util-cursor`. Live records the microphone only.

## Whispered v0.15.0 (Русский)

Загрузка на YouTube без терминала, часы, по которым видно, что долгая работа
LLM не зависла, и аккуратный подвал: какая LLM и какая модель распознавания
на каком оборудовании сейчас используются.

| Windows 11 (x64) | `Whispered-v0.15.0-windows-x64.zip` | превью без подписи — см. ниже |
| Linux (x86_64, Fedora) | `Whispered-v0.15.0-linux-x86_64.tar.gz` | превью, Live только с микрофона — см. ниже |

### Главное

- **Очередь загрузки на YouTube в приложении** — Файл → Очередь выгрузки на
  YouTube… показывает пакеты в очереди с состоянием каждой записи и загружает
  их (или обновляет отредактированные названия, описания и теги) с прогрессом
  и отменой. На последнем шаге мастера публикации появилась кнопка
  **Загрузить сейчас**. Окно не блокирует приложение; если его закрыть,
  загрузка продолжится.
- **Понятный прогресс** — шаги инсайтов и YouTube-пакета сообщают о каждом
  вызове LLM («Заголовки (2 из 6)…»), в подвале тикает прошедшее время, часы на
  экране запуска рецепта идут каждую секунду, а чат пишет «Думаю… м:сс», пока
  рассуждающая модель не выдаст первое слово.
- **Новый подвал** — плоские чипы с иконками вместо эмодзи. Чип LLM
  показывает модель, которая реально загружена в LM Studio; в его поповере —
  сервер, переключение профиля ИИ и повторная проверка. Чип распознавания
  («large-v3-turbo · Metal») переключает GPU и CPU. Чип очереди появляется,
  только когда в ней что-то есть.
- **Мастер публикации** — фото можно двигать и масштабировать в рамке, фото
  теперь выбирается и для первого спикера.
- **Исправления** — отклонённый Google вход в YouTube забывается, и можно
  войти заново, не нажимая сначала «Отключить».

### Известные ограничения

- Короткие клипы и окно презентации Live — по-прежнему ранние превью.
- Подвал показывает модель распознавания по умолчанию; рецепт со своей
  моделью использует её.

### Установка на macOS (сборка без подписи)

Сборки **не подписаны Apple Developer ID и не нотаризованы**. При первом
запуске Gatekeeper заблокирует приложение — это ожидаемо.

1. Распакуйте и переместите `Whispered.app` в `/Applications`.
2. Правый клик по `Whispered.app` → **Открыть** → **Открыть** в диалоге.
3. Если macOS всё ещё не пускает, один раз выполните в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

Движок whisper поставляется **внутри** приложения. Веса моделей скачиваются
при первом использовании.

### Установка на Windows (превью без подписи)

SmartScreen покажет «Система Windows защитила ваш компьютер»: нажмите
**Подробнее** → **Выполнить в любом случае**. Распакуйте архив и запустите
`Whispered.exe`.

### Установка на Linux (превью)

```bash
tar xzf Whispered-v0.15.0-linux-x86_64.tar.gz
./Whispered/Whispered
```

Нужны `ffmpeg` (`sudo dnf install ffmpeg-free`) и, под X11,
`xcb-util-cursor`. Live записывает только микрофон.
