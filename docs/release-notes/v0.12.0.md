## Whispered v0.12.0

A reworked workspace and a complete path from a recording to a published
YouTube video. The Library now lists records, the transcript reads as
paragraphs, and you can bookmark moments, keep your own notes and see where
Whisper wasn't sure. Covers get brand-deck layouts with speaker photos picked
from the video, and the publish wizard can queue packages for upload and
update videos already on YouTube.

### Downloads

| Platform | File | Notes |
|---|---|---|
| macOS (Apple Silicon) | `Whispered-v0.12.0-macos-arm64.zip` | macOS 13+; unsigned — see below |
| Windows 11 (x64) | `Whispered-v0.12.0-windows-x64.zip` | unsigned preview — see below |
| Linux (x86_64, Fedora) | `Whispered-v0.12.0-linux-x86_64.tar.gz` | preview, microphone-only Live — see below |

Verify your download against `SHA256SUMS.txt`:

```bash
shasum -a 256 -c SHA256SUMS.txt      # macOS / Linux
```
```powershell
(Get-FileHash Whispered-v0.12.0-windows-x64.zip -Algorithm SHA256).Hash
```

### Highlights

- **Library and record view** — a column of records with date groups and your
  own names for them; record tabs appear with their material and mark a failed
  step or a material made from an older transcript; the header says when, how
  long, which language and model. The window opens where you left it.
- **Transcript** — reads as paragraphs and follows playback; passages Whisper
  wasn't sure about are marked; a context menu (copy with timecode, bookmark,
  chapter, cut); bookmarks with `B`; click a speaker's name to rename speakers.
- **Notes and Insights** — your own notes, typed during a live session or
  later, feed Insights; Insights sections work as a filter and show task times.
- **Faster everyday controls** — a one-row player with click-to-seek and
  playback keys, a grouped forgiving `Ctrl+K`, a keyboard shortcuts sheet
  (`Ctrl+/`), a menu-bar icon for the recorder, live session and recent
  records, and a start screen that says whether the recipe can run and why not.
- **Covers** — brand-deck layouts; four ready speaker photos per participant
  picked from the video; zoom a photo inside its slot and frame it by dragging
  on the preview; a record remembers its cover setup.
- **YouTube** — a three-step publish wizard that keeps its edits per recording,
  descriptions ending with generated hashtags, an upload queue run with one
  command (`tools/youtube_autoupload.py`), and `--update` to push edited title,
  description and tags to videos already uploaded.
- **Local AI** — cleaning long recordings no longer repeats text or drops
  paragraphs; local requests skip hidden reasoning where they can and reuse the
  transcript prefix, so Insights come back faster.
- **Sources** — pick the latest recording from a saved folder; a Zoom
  `audio<N>.m4a` recording finds its video.
- **Fixes** — batch transcription no longer stalls on the first file, and
  cancelling a batch no longer freezes the window; the status bar follows a
  batch and reports its outcome; a downloaded model is no longer offered as
  "downloads on first launch"; a downloaded model is checked against its
  SHA-256 before it is used, and Live downloads a missing model the same
  way; a missing Whisper model
  opens the downloader in single and batch runs; a recipe's results stay with
  the record it started on.

### Known limitations

- Editing an uploaded video needs a newer YouTube permission: if you connected
  the account before this release, reconnect it in Settings → AI / LM Studio →
  YouTube account.
- Videos uploaded through the API by a Google project that has not passed
  Google's audit stay private until it does; you publish them in Studio.

### Installing on macOS (unsigned build)

These builds are **not signed with an Apple Developer ID and not notarized**
($99/year Apple Developer Program). Gatekeeper will block the first launch.
This is expected — the app is not doing anything unusual, it simply has no
paid signature.

1. Unzip and move `Whispered.app` to `/Applications`.
2. Right-click `Whispered.app` → **Open** → **Open** in the dialog. (A plain
   double-click only offers "Move to Trash".)
3. If macOS still refuses, run once in Terminal:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

The whisper transcription engine ships **inside** the app — no extra
install step. Model weights download on first use.

### Installing on Windows (unsigned preview)

No code-signing certificate yet, so SmartScreen shows
"Windows protected your PC". Click **More info** → **Run anyway**. Unzip
anywhere and run `Whispered.exe`.

### Installing on Linux (preview)

Built on Fedora 41. Extract and run:

```bash
tar xzf Whispered-v0.12.0-linux-x86_64.tar.gz
./Whispered/Whispered
```

It needs `ffmpeg` (`sudo dnf install ffmpeg-free`) and, under X11,
`xcb-util-cursor`. Live records the microphone only: system-audio capture is
macOS-only for now.

## Whispered v0.12.0 (Русский)

Переработанное рабочее пространство и полный путь от записи до опубликованного
видео на YouTube. Библиотека теперь показывает записи, транскрипт читается
абзацами, можно ставить закладки, вести свои заметки и видеть места, где
Whisper сомневался. Обложки получили макеты в стиле бренда с фото спикеров
из видео, а мастер публикации умеет ставить пакеты в очередь загрузки и
обновлять уже загруженные видео.

### Загрузки

| Платформа | Файл | Примечания |
|---|---|---|
| macOS (Apple Silicon) | `Whispered-v0.12.0-macos-arm64.zip` | macOS 13+; без подписи — см. ниже |
| Windows 11 (x64) | `Whispered-v0.12.0-windows-x64.zip` | превью без подписи — см. ниже |
| Linux (x86_64, Fedora) | `Whispered-v0.12.0-linux-x86_64.tar.gz` | превью, Live только с микрофона — см. ниже |

Проверьте загрузку по `SHA256SUMS.txt`:

```bash
shasum -a 256 -c SHA256SUMS.txt      # macOS / Linux
```
```powershell
(Get-FileHash Whispered-v0.12.0-windows-x64.zip -Algorithm SHA256).Hash
```

### Главное

- **Библиотека и запись** — колонка записей с группами по датам и вашими
  названиями; вкладки записи появляются вместе с материалом и отмечают
  упавший шаг или материал, сделанный по старому транскрипту; в шапке —
  когда, сколько длится, язык и модель. Окно открывается там, где его закрыли.
- **Транскрипт** — читается абзацами и следует за воспроизведением; места,
  где Whisper не уверен, отмечены; контекстное меню (копировать с таймкодом,
  закладка, глава, вырезать); закладки по `B`; клик по имени спикера
  переименовывает спикеров.
- **Заметки и Инсайты** — ваши заметки, набранные во время live-сессии или
  позже, идут в Инсайты; разделы Инсайтов работают как фильтр и показывают
  время задач.
- **Быстрое управление** — плеер в одну строку с перемоткой по клику и
  клавишами, сгруппированный «прощающий» `Ctrl+K`, шпаргалка клавиш
  (`Ctrl+/`), иконка в строке меню для записи, live-сессии и последних
  записей, старт-экран, который говорит, может ли рецепт запуститься и почему нет.
- **Обложки** — макеты в стиле бренда; по четыре готовых фото на участника из
  видео; масштаб фото в слоте и кадрирование перетаскиванием на превью;
  запись помнит настройку обложки.
- **YouTube** — мастер публикации в три шага, который хранит правки для каждой
  записи, хештеги в конце описания, очередь загрузки одной командой
  (`tools/youtube_autoupload.py`) и `--update`, чтобы отправить исправленные
  название, описание и теги в уже загруженное видео.
- **Локальный ИИ** — очистка длинных записей больше не повторяет текст и не
  теряет абзацы; локальные запросы по возможности обходятся без скрытых
  рассуждений и переиспользуют транскрипт, поэтому Инсайты приходят быстрее.
- **Источники** — выбор последней записи из сохранённой папки; запись Zoom
  `audio<N>.m4a` находит своё видео.
- **Исправления** — пакетная транскрипция больше не застревает на первом
  файле, а отмена пакета не замораживает окно; строка состояния показывает
  ход пакета и его итог; скачанная модель больше не значится как «скачается
  при первом запуске»; скачанная модель сверяется по SHA-256 до
  использования, и Live качает недостающую модель так же; при отсутствии
  модели Whisper
  открывается загрузчик в одиночном и пакетном режимах; результаты рецепта
  остаются у той записи, на которой он запущен.

### Известные ограничения

- Для правки загруженного видео нужно новое разрешение YouTube: если вы
  подключили аккаунт до этого релиза, переподключите его в Настройки →
  ИИ / LM Studio → Аккаунт YouTube.
- Видео, загруженные через API проектом Google, не прошедшим аудит, остаются
  приватными до его прохождения; публикуете вы их сами в Studio.

### Установка на macOS (сборка без подписи)

Сборки **не подписаны Apple Developer ID и не нотаризованы** (программа
Apple Developer — $99/год). При первом запуске Gatekeeper заблокирует
приложение. Это ожидаемо: приложение не делает ничего необычного, просто
у него нет платной подписи.

1. Распакуйте и переместите `Whispered.app` в `/Applications`.
2. Правый клик по `Whispered.app` → **Открыть** → **Открыть** в диалоге.
   (Обычный двойной клик предложит только «Переместить в корзину».)
3. Если macOS всё ещё не пускает, один раз выполните в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

Движок транскрипции whisper поставляется **внутри** приложения — отдельная
установка не нужна. Веса моделей скачиваются при первом использовании.

### Установка на Windows (превью без подписи)

Сертификата подписи кода пока нет, поэтому SmartScreen покажет
«Система Windows защитила ваш компьютер». Нажмите **Подробнее** →
**Выполнить в любом случае**. Распакуйте архив и запустите `Whispered.exe`.

### Установка на Linux (превью)

Собрано на Fedora 41. Распакуйте и запустите:

```bash
tar xzf Whispered-v0.12.0-linux-x86_64.tar.gz
./Whispered/Whispered
```

Нужны `ffmpeg` (`sudo dnf install ffmpeg-free`) и, под X11,
`xcb-util-cursor`. Live записывает только микрофон: захват системного звука
пока есть только на macOS.
