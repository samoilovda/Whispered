## Whispered v0.1.0

First public build of Whispered — a local desktop app that transcribes audio
and video with `whisper.cpp` and turns the transcript into subtitles,
articles, a YouTube package, insights, a book draft, or an editing timeline.
Transcription and diarization run entirely on your machine; AI text features
use a local LM Studio server by default.

### Downloads

| Platform | File | Notes |
|---|---|---|
| macOS (Apple Silicon) | `Whispered-v0.1.0-macos-arm64.zip` | macOS 13+; unsigned — see below |
| Windows 11 (x64) | `Whispered-v0.1.0-windows-x64.zip` | unsigned preview — see below |

Verify your download against `SHA256SUMS.txt`:

```bash
shasum -a 256 -c SHA256SUMS.txt      # macOS / Linux
```
```powershell
(Get-FileHash Whispered-v0.1.0-windows-x64.zip -Algorithm SHA256).Hash
```

### Highlights

- **Local transcription pipeline** — `whisper.cpp` in a cancellable child
  process, optional `pyannote` speaker diarization, `ffmpeg` format
  conversion.
- **Two-column workspace** — a searchable Library alongside the current
  document; one start screen picks a source and a recipe and launches it
  as a single job with per-step status, retry, and cancel.
- **Recipes** — five built-in step sets (transcript-only, YouTube video,
  podcast article, meeting notes, book) plus a user-editable slot:
  transcribe → clean, article, insights, YouTube package, book, cover, in
  any combination, artifacts auto-saved with provenance.
- **Library** — SQLite FTS5 full-text search across transcripts and
  generated materials, built-in audio player synced to an editable
  transcript, speaker renaming with reusable aliases, transcript version
  history with diff.
- **YouTube package** — titles, hook + summary description, chapter and
  key-question timecodes, tags; local LLM by default, optional user-keyed
  cloud provider.
- **Content tools** — transcript cleanup, article drafts in 5 formats, AI
  chat with the transcript, insights, book pipeline, Cut tab with EDL
  export.
- **9 export formats** — TXT, TXT+timestamps, SRT, VTT, JSON, MD, HTML,
  DOCX, PDF — plus one-click export presets (YouTube / article draft /
  full archive).
- **Polish** — RU/EN interface, dark/light themes, microphone recorder,
  batch queue, watch-folder intake, custom vocabulary.

### Known limitations

- Builds are **unsigned** on both platforms (see install steps below).
- macOS build targets **Apple Silicon** only; no Intel build yet.
- Linux is source-install only; the AppImage script is not a validated
  release channel.
- Speaker diarization needs a one-time Hugging Face token setup
  (`setup_diarization.py`).
- AI text features need a local [LM Studio](https://lmstudio.ai) server
  running; transcription, editing, history, and export do not.

### Installing on macOS (unsigned build)

This build is **not signed with an Apple Developer ID and not notarized**
($99/year Apple Developer Program). Gatekeeper will block the first launch.
This is expected — the app is not doing anything unusual, it simply has no
paid signature.

1. Unzip and move `Whispered.app` to `/Applications`.
2. Right-click `Whispered.app` → **Open** → **Open** in the dialog. (A plain
   double-click only offers "Move to Trash".)
3. If macOS still refuses, run once in Terminal:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

The whisper transcription engine ships **inside** the app — no extra install
step. Model weights download on first use.

### Installing on Windows (unsigned preview)

No code-signing certificate yet, so SmartScreen shows "Windows protected your
PC". Click **More info** → **Run anyway**. Unzip anywhere and run
`Whispered.exe`.

## Whispered v0.1.0 (Русский)

Первая публичная сборка Whispered — локального десктопного приложения,
которое расшифровывает аудио и видео через `whisper.cpp` и превращает
транскрипт в субтитры, статьи, YouTube-пакет, инсайты, черновик книги или
монтажный таймлайн. Транскрипция и диаризация выполняются полностью на вашей
машине; AI-функции работы с текстом по умолчанию используют локальный сервер
LM Studio.

| Windows 11 (x64) | `Whispered-v0.1.0-windows-x64.zip` | превью без подписи — см. ниже |

Проверьте загрузку по `SHA256SUMS.txt`:

```bash

```
```powershell

```

### Главное

- **Локальный конвейер транскрипции** — `whisper.cpp` в отменяемом
  дочернем процессе, опциональная диаризация `pyannote`, конвертация
  форматов через `ffmpeg`.
- **Двухколоночная рабочая область** — библиотека с поиском рядом с
  текущим документом; стартовый экран выбирает источник и рецепт и
  запускает его одной задачей с постатусным прогрессом, повтором и
  отменой.
- **Рецепты** — пять встроенных наборов шагов (только транскрипт,
  YouTube-видео, статья для подкаста, заметки встречи, книга) плюс
  редактируемый слот: транскрипция → очистка, статья, инсайты,
  YouTube-пакет, книга, обложка в любых сочетаниях; артефакты
  сохраняются автоматически с происхождением.
- **Библиотека** — полнотекстовый поиск SQLite FTS5 по транскриптам и
  сгенерированным материалам, встроенный аудиоплеер, синхронизированный с
  редактируемым транскриптом, переименование спикеров с повторно
  используемыми алиасами, история версий транскрипта с диффом.
- **YouTube-пакет** — заголовки, описание (хук + резюме), таймкоды глав и
  ключевых вопросов, теги; локальная LLM по умолчанию, опциональный
  облачный провайдер по ключу пользователя.
- **Инструменты для контента** — очистка транскрипта, черновики статей в
  5 форматах, AI-чат с транскриптом, инсайты, конвейер книги, вкладка Cut
  с экспортом EDL.
- **9 форматов экспорта** — TXT, TXT+таймстемпы, SRT, VTT, JSON, MD, HTML,
  DOCX, PDF — плюс пресеты экспорта в один клик (YouTube / черновик статьи
  / полный архив).
- **Отделка** — RU/EN интерфейс, тёмная/светлая темы, запись с микрофона,
  пакетная очередь, папка-наблюдатель, пользовательский словарь.

### Известные ограничения

- Сборки **без подписи** на обеих платформах (см. установку ниже).
- Сборка macOS только для **Apple Silicon**; сборки под Intel пока нет.
- Linux — только установка из исходников; скрипт AppImage не является
  проверенным каналом релиза.
- Диаризация спикеров требует разовой настройки токена Hugging Face
  (`setup_diarization.py`).
- AI-функции работы с текстом требуют запущенного локального сервера
  [LM Studio](https://lmstudio.ai); транскрипция, редактирование, история
  и экспорт — нет.

### Установка на macOS (сборка без подписи)

Сборка **не подписана Apple Developer ID и не нотаризована** (программа
Apple Developer — $99/год). При первом запуске Gatekeeper заблокирует
приложение. Это ожидаемо: приложение не делает ничего необычного, просто у
него нет платной подписи.

1. Распакуйте и переместите `Whispered.app` в `/Applications`.
2. Правый клик по `Whispered.app` → **Открыть** → **Открыть** в диалоге.
   (Обычный двойной клик предложит только «Переместить в корзину».)
3. Если macOS всё ещё не пускает, один раз выполните в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

Движок транскрипции whisper поставляется **внутри** приложения — отдельная
установка не нужна. Веса моделей скачиваются при первом использовании.

### Установка на Windows (превью без подписи)

Сертификата подписи кода пока нет, поэтому SmartScreen покажет «Система
Windows защитила ваш компьютер». Нажмите **Подробнее** → **Выполнить в
любом случае**. Распакуйте архив и запустите `Whispered.exe`.
