## Whispered v0.13.0

Speaker labels now work out of the box and fully offline: no Hugging Face
account, no torch, and the transcript you already have can get its speakers
too. Model downloads are verified, and the local AI writes better YouTube
packages and cleans Russian speech better.

### Downloads

| Platform | File | Notes |
|---|---|---|
| macOS (Apple Silicon) | `Whispered-v0.13.0-macos-arm64.zip` | macOS 13+; unsigned — see below |
| Windows 11 (x64) | `Whispered-v0.13.0-windows-x64.zip` | unsigned preview — see below |
| Linux (x86_64, Fedora) | `Whispered-v0.13.0-linux-x86_64.tar.gz` | preview, microphone-only Live — see below |

Verify your download against `SHA256SUMS.txt`:

```bash
shasum -a 256 -c SHA256SUMS.txt      # macOS / Linux
```
```powershell
(Get-FileHash Whispered-v0.13.0-windows-x64.zip -Algorithm SHA256).Hash
```

### Highlights

- **Speakers, offline** — turn on 👥 Speakers or pick a recipe with the
  Speakers step. The first run downloads two models (46 MB, checksum-verified);
  nothing else to install or sign up for. The number of speakers is detected,
  or set it in Settings → Diarization. On two-person Zoom calls checked against
  each participant's own audio track, speakers were mixed up in 0.2–2.6 % of
  the speech; mixes of 3–5 voices were counted correctly.
- **Detect Speakers** — in the Transcribe menu and `Ctrl+K`: labels a
  transcript that has none (an older record, a Live session, a run with
  speakers off) and saves it as a new version, keeping speaker names you gave.
- **Verified model downloads** — a downloaded Whisper model is checked against
  its size and SHA-256; Live downloads a missing model before it starts.
- **YouTube** — titles and the description get a second, reviewing pass and
  learn from the titles and descriptions you approved on other records.
- **Cleaning** — Russian speech is cleaned with a Russian prompt in larger
  chunks, and a term glossary keeps names and jargon intact in cleaning and
  Insights.
- **Window** — `Cmd+W` closes the window; the menu-bar icon is off by default
  (Settings turns it on).
- **Fixes** — the Cover workspace can be left and saved to the record, and its
  inspector scrolls instead of squeezing its fields.

### Known limitations

- Speakers are labelled per transcript sentence, so a short remark inside
  someone else's sentence is not split out.
- Editing an uploaded video needs the newer YouTube permission from v0.12.0:
  reconnect the account in Settings if you connected it earlier.

### Installing on macOS (unsigned build)

These builds are **not signed with an Apple Developer ID and not notarized**.
Gatekeeper will block the first launch; this is expected.

1. Unzip and move `Whispered.app` to `/Applications`.
2. Right-click `Whispered.app` → **Open** → **Open** in the dialog.
3. If macOS still refuses, run once in Terminal:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

The whisper transcription engine ships **inside** the app. Model weights
download on first use.

### Installing on Windows (unsigned preview)

SmartScreen shows "Windows protected your PC": click **More info** →
**Run anyway**. Unzip anywhere and run `Whispered.exe`.

### Installing on Linux (preview)

```bash
tar xzf Whispered-v0.13.0-linux-x86_64.tar.gz
./Whispered/Whispered
```

It needs `ffmpeg` (`sudo dnf install ffmpeg-free`) and, under X11,
`xcb-util-cursor`. Live records the microphone only.

## Whispered v0.13.0 (Русский)

Разметка спикеров теперь работает сразу и полностью офлайн: без аккаунта
Hugging Face и без torch, а спикеров можно определить и в уже готовом
транскрипте. Загрузки моделей проверяются, а локальный ИИ лучше пишет
пакеты для YouTube и чистит русскую речь.

### Загрузки

| Платформа | Файл | Примечания |
|---|---|---|
| macOS (Apple Silicon) | `Whispered-v0.13.0-macos-arm64.zip` | macOS 13+; без подписи — см. ниже |
| Windows 11 (x64) | `Whispered-v0.13.0-windows-x64.zip` | превью без подписи — см. ниже |
| Linux (x86_64, Fedora) | `Whispered-v0.13.0-linux-x86_64.tar.gz` | превью, Live только с микрофона — см. ниже |

Проверьте загрузку по `SHA256SUMS.txt`:

```bash
shasum -a 256 -c SHA256SUMS.txt      # macOS / Linux
```
```powershell
(Get-FileHash Whispered-v0.13.0-windows-x64.zip -Algorithm SHA256).Hash
```

### Главное

- **Спикеры офлайн** — включите 👥 Спикеры или выберите рецепт с шагом
  «Спикеры». При первом запуске скачиваются две модели (46 МБ, с проверкой
  контрольных сумм); больше ничего ставить и регистрировать не нужно. Число
  спикеров определяется само или задаётся в Настройки → Диаризация. На звонках
  Zoom вдвоём, сверенных с отдельной дорожкой каждого участника, спикеры
  перепутаны в 0,2–2,6 % речи; в смесях из 3–5 голосов их число определено верно.
- **Определить спикеров** — в меню «Транскрибация» и в `Ctrl+K`: размечает
  транскрипт без спикеров (старую запись, live-сессию, запуск без спикеров) и
  сохраняет его новой версией, сохраняя данные вами имена.
- **Проверка загрузок** — скачанная модель Whisper сверяется по размеру и
  SHA-256; Live скачивает недостающую модель перед стартом.
- **YouTube** — название и описание проходят второй, проверочный проход и
  учатся на названиях и описаниях, которые вы одобрили в других записях.
- **Очистка** — русская речь чистится русским промптом более крупными
  кусками, а глоссарий терминов сохраняет имена и жаргон при очистке и в Инсайтах.
- **Окно** — `Cmd+W` закрывает окно; иконка в строке меню по умолчанию
  выключена (включается в Настройках).
- **Исправления** — из рабочей области обложки можно выйти и сохранить её в
  запись, а её инспектор прокручивается, а не сжимает поля.

### Известные ограничения

- Спикер ставится на предложение транскрипта, поэтому короткая реплика внутри
  чужой фразы отдельно не выделяется.
- Для правки загруженного видео нужно разрешение YouTube из v0.12.0:
  переподключите аккаунт в Настройках, если подключали его раньше.

### Установка на macOS (сборка без подписи)

Сборки **не подписаны Apple Developer ID и не нотаризованы**. При первом
запуске Gatekeeper заблокирует приложение — это ожидаемо.

1. Распакуйте и переместите `Whispered.app` в `/Applications`.
2. Правый клик по `Whispered.app` → **Открыть** → **Открыть** в диалоге.
3. Если macOS всё ещё не пускает, один раз выполните в Терминале:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Whispered.app
   ```

Движок whisper поставляется **внутри** приложения. Веса моделей скачиваются
при первом использовании.

### Установка на Windows (превью без подписи)

SmartScreen покажет «Система Windows защитила ваш компьютер»: нажмите
**Подробнее** → **Выполнить в любом случае**. Распакуйте архив и запустите
`Whispered.exe`.

### Установка на Linux (превью)

```bash
tar xzf Whispered-v0.13.0-linux-x86_64.tar.gz
./Whispered/Whispered
```

Нужны `ffmpeg` (`sudo dnf install ffmpeg-free`) и, под X11,
`xcb-util-cursor`. Live записывает только микрофон.
