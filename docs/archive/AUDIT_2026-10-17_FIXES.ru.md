## Целостность и переход существующих данных

1. **Кэш.** Старые ревизии и манифесты без `content_sha256` не считаются
   пригодным кэшем. Файлы остаются на диске; успешная повторная генерация
   заменяет их атомарно. Ошибка/отмена до commit сохраняет старый файл.
2. **Сбой между output и manifest.** Два replace не объявляются общей
   файловой транзакцией. Если процесс падает между ними, digest делает пару
   непригодной для reuse. Частичный JSON не заменяет старый полноценный файл.
   Digest считается по staged bytes, а не по произвольному позднему состоянию output.
3. **Версии.** Старые сохранённые payload не переписываются; первая ревизия
   нового формата может создать дополнительную версию. Начальная версия
   транскрипта сохраняется существующей политикой retention.
4. **YouTube.** Старый pending без идентичности пакета требует явного restart.
   Клиент не продолжает его молча и не меняет metadata/privacy автоматически.
   Проверка Studio нужна из-за возможности уже завершённой прежней загрузки.
5. **Удаление.** Удаляется логическая запись и связанные строки БД. Исходные
   медиа, экспорты, заметки, логи и очередь YouTube не удаляются. Для отмены
   ранее одобренного queued upload необходимо отдельно удалить соответствующий
   `youtube_upload.queued.json` перед запуском CLI. Гарантированное стирание
   SQLite/WAL и файлов здесь не реализуется и не обещается.

## Дополнительные рекомендации CI и документации

- Внешние Actions закреплены полными SHA, полученными через read-only Git.
- По умолчанию workflow имеют `contents: read`; `contents: write` остаётся
  только у job публикации релиза.
- Release version проверяется до сборки. В shell значение передаётся через
  environment, а не интерполяцией input в текст команды.
- `dependency-audit.yml` проверяет четыре lock-файла при изменениях,
  вручную и еженедельно; advisory не игнорируются.
- Linux packaging устанавливает полный `requirements-build-linux.lock`;
  CPU runtime совпадает с основным runtime lock. Fedora job получает PortAudio.
- Обновлены документация engine, кэша и журнал `LLM_RESEARCH.ru.md`.
- Исправлены сохранённые `install_script` и `start_skill`: старый override
  mypy 1.17.1 удалён. Новый install script выполнен в текущей машине;
  конфигурация сохранена в черновике. Публикация среды не выполнялась.

  вызывались. Их отсутствие не заменялось фиктивным утверждением о работе API.

  совместимости бинарника с Fedora или другими версиями glibc. Fedora,
  macOS и Windows packaging jobs необходимо выполнить в их целевых средах.
- GitHub workflows проверяются локально actionlint; удалённые workflows,
  push, релиз и публикация среды не запускались.
- Полный SBOM нативных библиотек, дальнейшая декомпозиция крупных UI/registry
  модулей и расширение type coverage остаются отдельными рекомендациями
  сопровождения. Они не объявляются выполненными исправлениями A01–A14.
