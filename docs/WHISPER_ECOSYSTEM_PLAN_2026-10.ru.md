# Заимствования из экосистемы Whisper: план для агента

Статус: черновик задания от 2026-10-16, ни один шаг не начат.
Владелец решений: пользователь. Агент выполняет шаги Ш0…Ш10 строго по
порядку и останавливается на гейтах **STOP**. Правила проекта (`CLAUDE.md`)
действуют целиком: офлайн, не блокировать UI, всё долгое отменяемо и живёт в
`WorkerRegistry`, настройки через `Config`, i18n через `Retranslator`/`tr_count`,
один шаг = один коммит, полный pre-commit gate перед каждым коммитом.

Соответствие пунктам обсуждения: Ш1 = VAD (1), Ш2 = фильтры галлюцинаций (2),
Ш3 = Core ML (10), Ш4 = пословные метки (3), Ш5 = спикер на слово (5),
Ш6 = профили голосов (6), Ш7 = Zoom multitrack (7), Ш8 = Live (11),
Ш9 = watch-папка с рецептом (13), Ш10 = глобальная диктовка (12).

## 0. TL;DR для агента

1. Сначала измеритель (Ш0), потом изменения. Каждое изменение качества
   распознавания доказывается цифрами из `tools/bench_asr.py` до/после.
2. Всё, что нужно, уже есть в установленной `pywhispercpp` (1.5.0, whisper.cpp
   с VAD и DTW): параметры `vad`/`vad_model_path`, `entropy_thold`/
   `logprob_thold`, context-параметры `dtw_token_timestamps`/`dtw_aheads_preset`,
   функции `whisper_vad_*` и `whisper_full_get_token_data` (поле `t_dtw`).
   Новых тяжёлых зависимостей (torch, WhisperX, faster-whisper) не добавлять.
3. Новые модели (Silero VAD, Core ML-энкодеры) скачиваются только через
   `core/model_manifest.py` + `ModelRepository.ensure()` с размером и sha256 из
   закреплённого коммита Hugging Face.
4. Любая новая функция по умолчанию либо выключена, либо доказанно не ухудшает
   метрики Ш0. Отключение возвращает ровно прежнее поведение.
5. Ручные проверки на железе, разрешения ОС и решения «включать ли по
   умолчанию» делает владелец — агент готовит всё и останавливается.

## 2. Мультиплатформенность Ш9 и Ш10 (проверка)

**Ш9 — watch-папка с рецептом: да, полностью.** `QFileSystemWatcher` и
`QTimer` кроссплатформенны, на сетевых и облачных папках, где события не
приходят, страхует уже существующая перепроверка по таймеру. `JobEngine` и
рецепты не зависят от Qt и ОС. Платформенных оговорок нет.

**Ш10 — глобальная диктовка: да, с одной честной деградацией.**

| Платформа | Глобальная клавиша | Вставка текста в активное окно | Итог |
|---|---|---|---|
| macOS 13+ | `pynput` (Quartz event tap) | `pynput` → Cmd+V через CGEvent | полностью; нужны разрешения «Универсальный доступ» и «Мониторинг ввода» |
| Windows 11 | `pynput` (low-level hook) | `pynput`/`SendInput` → Ctrl+V | полностью; не вставляет в окна, запущенные от администратора (UIPI) |
| Linux X11 | `pynput` (Xlib) | `pynput` → Ctrl+V | полностью |
| Linux Wayland (Fedora по умолчанию) | портал `org.freedesktop.portal.GlobalShortcuts` через `PyQt6.QtDBus` (GNOME ≥ 48, KDE ≥ 5.27); иначе — только из окна/трея | стандартного способа нет → текст в буфер обмена + уведомление «вставьте Ctrl+V» | клавиша — да на современных DE, автовставка — нет |

Оговорки для macOS: разрешения TCC привязаны к подписи приложения, у
неподписанной сборки они слетают после каждой пересборки — это задокументировать,
а не обходить. `PyQt6.QtDBus` в установленном колесе есть (проверено импортом).

**Сделать.**

  средняя и p90 ошибка границ слов против эталона с метками.

**DoD.** `bench_asr.py --config baseline` даёт отчёт на 1 коротком файле.

## 5. Риски

- **Приватный `_ctx` pywhispercpp (Ш4).** Ревизия закреплена в setup-скриптах;
  тест-канарейка падает при смене API.
- **DTW и flash attention (Ш4).** Возможна потеря скорости — мерить, слова
  включать только по запросу (экспорт субтитров/караоке/рецепт).
- **Ложные удаления фильтром (Ш2).** Ничего не удалять без нулевых ложных
  удалений на эталонах; при сомнении — пометка низкой уверенности.
- **Биометрия (Ш6).** Только опт-ин и только локально.
- **Разрешения ОС (Ш10).** На macOS неподписанная сборка теряет TCC-доступ
  при пересборке; на Wayland автовставка недоступна в принципе.
- **Нагрузка на LM Studio (Ш9).** Очередь рецептов не должна запускать
  параллельные LLM-запросы (см. Local LLM gotchas в `CLAUDE.md`).
