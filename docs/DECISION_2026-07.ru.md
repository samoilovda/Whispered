# Whispered: стоит ли продолжать. Разбор для решения

*Дата: 16 июля 2026. Автор: агент (Claude), по запросу владельца.
Все цифры получены измерением этой кодовой базы и прогонами на реальном
аудио владельца, кроме явно помеченных как внешние источники.*

---

## Короткий ответ

**Продолжать — но не догоняя MacWhisper.** Гнаться за паритетом
бессмысленно: 90% того, чем MacWhisper тебя обходит (диктовка,
реалтайм-субтитры, детект встреч), к твоим задачам отношения не имеет.
А то, ради чего ты вообще открываешь приложение — русский подкаст →
главы, описание, статья — **не умеет ни один конкурент**, ни за €59, ни
за подписку.

Ключевая цифра: из 15 200 строк продакшн-кода **5 200 — это контент-конвейер
на LLM**, которому нет замены на рынке, и **3 700 — транскрипция**, которую
MacWhisper делает лучше тебя за €59.

Отсюда развилка, и она не про «пилить или бросить», а про **что именно
пилить**. Разбор ниже.

---

## 1. Что Whispered реально умеет сейчас

Проверено по коду, не по README.

**Ядро:**
- whisper.cpp в отменяемом дочернем процессе; на M4 Pro — **23.4x реального
  времени** на `large-v3-turbo` с Metal (замерено на 90-секундном русском
  клипе). 8 моделей на выбор, перевод на английский, кастомный словарь.
- Диаризация (pyannote), извлечение аудио из видео через ffmpeg.
- 9 форматов экспорта: TXT, TXT+таймкоды, SRT, VTT, JSON, MD, HTML, DOCX, PDF.

**Контент-конвейер (то, ради чего всё):**
- YouTube-пакет: заголовки, описание с хуком, главы с таймкодами (≤7.5 мин
  между метками), тайм-коды ключевых вопросов, теги.
- Статьи в 5 форматах, чистка транскрипта, чат с транскриптом, инсайты
  (главы / action items / ключевые моменты), книжный пайплайн.
- 17 промптов отдельными Markdown-файлами — правятся без кода.
- Локальная LLM через LM Studio по умолчанию; облачный провайдер — опция
  на своём ключе.

**Обвязка:**
- Библиотека с историей и полнотекстовым поиском (SQLite FTS5), плеер,
  редактируемый транскрипт с переименованием спикеров, пресеты-цепочки
  в одну кнопку, очередь, запись с микрофона, RU/EN локализация, темы.
- Cut/EDL-экспорт для монтажа.
- Standalone `.app` (121 МБ) + скрипт AppImage.

**Качество кода:** 292 юнит-теста, ruff-clean, headless-смоук в пре-коммит
гейте. 84 файла, ~15 200 строк продакшна + 2 700 тестов.

### Где деньги лежат

| Область | Строк | Есть ли замена на рынке |
|---|---:|---|
| Контент-конвейер (LLM) | 5 204 | **Нет** (для русского — точно) |
| Транскрипция и обвязка | 3 720 | Да — MacWhisper, €59 |
| Инфраструктура (темы, i18n, история, сборка) | 3 104 | Да, но она у тебя уже есть |
| Видео/Cut | 855 | Частично (Descript, резолв) |

## 2. Что умеют конкуренты

**MacWhisper** (€59 разово, macOS+iOS) — эталон в своей нише:
- Захват системного звука и **автозапись встреч** (Zoom, Teams, Webex,
  Skype, Discord).
- **Транскрипция по YouTube-ссылке** и по URL.
- Системная диктовка (зажал клавишу — текст в любом приложении).
- Реалтайм-субтитры с живым переводом (микрофон или системный звук).
- Не-whisper модели (Parakeet и др.), 100+ языков.
- Диаризация (бета), SRT/VTT/DOCX/PDF/MD/HTML/CSV, батч по папкам.
- Подписанное приложение, App Store, MDM, скидки, iOS-компаньон.
- BYOK-интеграция с AI-провайдерами; облачный «Ассистент» — отдельная подписка.

**Superwhisper / Voibe** — про диктовку, не про файлы. К твоим задачам
отношения не имеют.

*Источник по MacWhisper: обзоры и поиск (официальная страница — SPA, машинно
не читается). По-крупному сходится, детали могли устареть — релизы частые.*

### Чего у конкурентов нет

Ни у кого нет твоего конвейера: русский транскрипт → **главы с осмысленными
названиями, описание, теги, статьи** на локальной LLM, офлайн, с промптами
в открытых Markdown-файлах. У MacWhisper AI-функции есть, но они generic
(«суммаризируй») и в облаке за подписку. Книжный пайплайн и Cut/EDL —
тоже мимо их продукта.

## 3. Разрыв — применительно к твоим задачам

Твои задачи (по содержимому `input/` и истории): длинные русские интервью
и подкасты на 45–60 минут, теперь плюс английский, результат — YouTube-пакет
и статьи. Отсюда фильтр: что из фич MacWhisper тебе **правда** нужно.

| Фича MacWhisper | Нужна тебе? | Почему |
|---|---|---|
| Диктовка в любое приложение | **Нет** | Ты не диктуешь, ты расшифровываешь файлы |
| Реалтайм-субтитры + живой перевод | **Нет** | Работа пост-фактум |
| Автодетект встреч (Zoom/Teams) | **Скорее нет** | Записи у тебя уже готовыми файлами |
| Захват системного звука | **Может быть** | Если начнёшь писать созвоны сам |
| **Транскрипция по YouTube-ссылке** | **Да** | Ты работаешь с YouTube-контентом, сейчас качаешь руками |
| **Выбор движка (Parakeet/GigaAM)** | **Да** | Прямо влияет на качество глав и статей |
| Подписанная сборка | Только для раздачи | Себе ты собираешь сам |
| iOS, MDM, App Store | Нет | Не твой сценарий |

**Вывод: реальный разрыв — две позиции**, а не двадцать. Всё остальное —
их продукт, не твой.

## 4. Объём работ до «уровня конкурентов для твоих задач»

Оценки — рабочие дни для одного человека с агентом. Основаны на том, что
точки сцепления в коде узкие: `pywhispercpp` импортируется ровно в одном
месте (`transcriber.py:213`), а всё ниже по конвейеру видит только
`Segment(start, end, text, speaker)` и про движок не знает.

| Задача | Оценка | Риск | Нужно ли для твоих задач |
|---|---:|---|---|
| **Подключаемые движки** (GigaAM/Parakeet) | 3–5 д | Средний | Да |
| **YouTube-ссылка на вход** (yt-dlp) | 1–2 д | Низкий | Да |
| **Надёжность LLM** (последовательные воркеры, не сохранять ошибки) | 1–2 д | Низкий | Да — болит сейчас |
| Захват системного звука (только macOS) | 3–5 д | Высокий | Опционально |
| Подписанный + нотаризованный DMG | 1–2 д + $99/год | Низкий | Только для раздачи |
| Windows | 5–10 д | Высокий | Только для портфолио |
| Диктовка / реалтайм | 10+ д | Высокий | **Нет** |

**Итого для твоих задач: ~2 недели.** Не два месяца. Приложение уже
покрывает 90% твоего сценария — 23.4x реального времени на транскрипции
работают прямо сейчас.

### Что показал спайк по движкам (16.07)

Уже сделано и измерено на твоём аудио, 90 секунд, M4 Pro:

| Движок | Скорость | Замечание |
|---|---|---|
| whisper.cpp turbo (сейчас) | **23.4x** | эталон, связный полный текст |
| GigaAM v3 e2e + VAD | **33.6x** | пунктуация и заглавные сама |
| Parakeet TDT v3 | **20.5x** | сопоставим с turbo |
| Whisper через ONNX | **0.5x** | тупик, в ~45 раз медленнее |

Три находки, которые надо помнить при интеграции:
1. **ONNX-whisper — тупик** → pywhispercpp остаётся, `onnx-asr` берём
   только под GigaAM/Parakeet. Движка будет два.
2. **CoreML не работает** ни с одной моделью → пока только CPU.
   Аппаратное ускорение на Apple Silicon — открытый риск для macOS-first.
3. **Режим прогона у каждой модели свой**: GigaAM без VAD молча теряет
   текст (окно ~25 с), Parakeet от VAD ломается — детектит язык на каждом
   чанке и уплывает в украинский. Язык у Parakeet форсировать нельзя —
   а Whispered даёт выбор языка. Конфликт проверить до интеграции.

Спайк **направляющий, не решающий**: эталонного текста нет, WER не считали.
Чтобы выбрать движок обоснованно — нужна вычитанная вручную 90-секундная
расшифровка (~15 минут твоего времени).

## 5. Сколько стоит поддержка

Здесь без прикрас — это главный риск проекта, и он не в коде.

**Что делает поддержку дорогой:**

1. **Хрупкая сборка.** Каждая из этих проблем стоила отдельной отладочной
   сессии: `freeze_support` (клик по Process открывал второе окно вместо
   транскрипции), пропавший `platformdirs` в дочернем процессе, CoreML,
   внешний whisper-стек. PyInstaller + PyQt6 + нативные библиотеки — это
   постоянный источник поломок, которые ловятся только руками.
2. **Тесты не ловят UI.** 292 теста идут на заглушках Qt — они зелёные, но
   на прошлой неделе Gemini внёс маленькую правку интерфейса, и **две
   регрессии тесты не увидели**: сплиттер работал наоборот заявленному, а
   подписи обрезались после увеличения шрифта. Нашлись только глазами на
   скриншоте. Любая UI-правка требует ручного осмотра.
3. **Внешние рантаймы, которые ты не контролируешь.** ffmpeg, LM Studio
   (документированно виснет на длинных транскриптах и параллельных
   запросах), модели, HF-хаб. Каждый — точка отказа.
4. **Экосистема моделей движется быстро.** Parakeet v3 — сентябрь 2025,
   GigaAM v3 — ноябрь 2025. Раз в несколько месяцев появляется что-то,
   что стоит перепроверить.
5. **Мультиплатформенность умножает поверхность.** Каждая платформа × каждый
   движок = отдельный прогон.

**Оценка в часах:**

| Режим | Поддержка | Что входит |
|---|---:|---|
| **Личный инструмент, macOS** | 2–4 ч/мес | Обновления зависимостей, чинить после апдейтов macOS |
| **+ Linux и Windows** | 6–10 ч/мес | ×3 поверхность тестирования, сборки |
| **Публичный продукт** | 1–2 д/мес, вначале больше | Релизы, подписи, вопросы пользователей, issues |

Хорошая новость: пре-коммит гейт (ruff + 292 теста + headless-смоук),
чистая архитектура и `CLAUDE.md` с правилами реально работают — этот проект
дешевле в поддержке, чем типичный vibecoded. Плохая — это всё равно
2–4 часа в месяц навсегда, просто чтобы не сгнило.

## 6. Варианты

**A. Личный инструмент, macOS-only.**
Забить на Windows, дистрибуцию, подпись. Сделать две нужные вещи
(YouTube-ссылка, надёжность LLM), движки — по желанию.
→ ~1 неделя работы, 2–4 ч/мес поддержки. Максимум пользы на единицу боли.

**B. Портфолио / open-source продукт.**
Плюс Windows, Flathub, подписанный DMG, скриншоты, ответы на issues.
→ +2–3 недели, 1–2 д/мес навсегда. Оправдано, только если приложение
работает на тебя как витрина — тогда это инвестиция не в софт, а в резюме.

**C. Бросить, купить MacWhisper.**
€59, лучше транскрипция, ноль поддержки. **Но** ты теряешь контент-конвейер
— 5 200 строк, которым нет замены. Реалистично только если YouTube-пакеты
тебе больше не нужны.

**D. Гибрид: MacWhisper на вход, Whispered на контент.**
MacWhisper расшифровывает (ссылки, встречи, движки — их забота), Whispered
жуёт готовый транскрипт в контент.
→ Звучит логично, но на практике это ручной перенос файлов между
приложениями на каждой итерации, а транскрипция у тебя **уже работает**
на 23.4x. Платить €59 и городить шов ради того, что не сломано, смысла нет.

## 7. Рекомендация

**Вариант A, с оговоркой.**

Обоснование:
- Твоя транскрипция не сломана — 23.4x реального времени, качество на
  уровне. Догонять тут нечего.
- Реальный разрыв — две позиции (YouTube-ссылка, выбор движка) и обе
  дешёвые: ~1 неделя.
- Всё остальное в MacWhisper — их продукт для их аудитории. Диктовка и
  реалтайм-субтитры к твоей работе отношения не имеют, и повторять их —
  это месяцы работы ради фич, которыми ты не будешь пользоваться.
- Уникальное у тебя — контент-конвейер, и его конкуренты не закрывают
  **вообще**. Туда и надо вкладывать, а не в паритет.

Оговорка: если приложение для тебя — **портфолио**, экономика другая.
Тогда Windows и подписанная сборка перестают быть блажью и становятся
пунктом, ради которого всё и делается. Это единственная причина брать
вариант B, и решать её надо честно: витрина или инструмент.

**Что бы я сделал в следующие две недели:**
1. Надёжность LLM (1–2 д) — единственное, что болит прямо сейчас.
2. YouTube-ссылка на вход (1–2 д) — убирает ручной шаг из каждой итерации.
3. Вычитать 90 секунд эталона (15 мин твоего времени) → посчитать WER →
   решить по движкам на цифрах, а не на ощущениях.
4. Движки (3–5 д) — только если WER покажет, что есть за что бороться.

**Чего бы не делал:** диктовку, реалтайм-субтитры, детект встреч, iOS.
Windows — только под решение «это портфолио».

## Приложение: методология и оговорки

- Метрики кода — прямым измерением репозитория на 16.07.2026 (`wc -l`,
  `git log`, 84 файла Python).
- Скорость движков — прогоны на `input/audio1170954204.m4a`, срез 90 с,
  M4 Pro. Скрипты в скретчпаде сессии, в репозиторий не входят.
- Оценки трудозатрат — экспертные, на основе реальных точек сцепления в
  коде. Дни рабочие, для одного человека с агентом. Погрешность вверх
  выше, чем вниз: хрупкость сборки исторически съедала больше, чем
  закладывалось.
- Фичи MacWhisper — из вторичных источников (обзоры, поиск), официальная
  страница машинно не читается. Релизы частые, детали могли устареть.
- Заявление GigaAM «70:30 против Whisper-large-v3» — слова вендора, против
  `large-v3`, а не против твоего `turbo`.
- Сравнение WER между источниками меряно на разных наборах и строго
  говоря несопоставимо. Решающим может быть только замер на твоём аудио.
