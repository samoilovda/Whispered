# План для Sonnet: переработка UI/UX Whispered

> **Контекст.** Whispered — privacy-first PyQt6-приложение: транскрипция
> (whisper.cpp) + генерация контента (локальный LM Studio, опц. облако для
> YouTube). Текущий интерфейс перегружен: 2-строчная шапка с шестью
> контролами, левая колонка с 4 стековыми панелями и 7 чекбоксами форматов,
> 8 вкладок справа, переключатель трёх «режимов», прячущий/показывающий
> панели. Цель редизайна: **современный, опрятный интерфейс, где ежедневные
> действия доступны в 1 клик с первого экрана**, а редкие — убраны с глаз,
> но не глубже одного диалога.
>
> Читать вместе с: `docs/STRATEGY.md` (ценности и целевой сценарий),
> `docs/plans/SONNET_FIXES_PLAN.md` (выполнить **до** этого плана — особенно
> F1 тесты и F4 closeEvent). Правила работы — `ROADMAP.md` §1.
> Документ самодостаточен; выполняется фазами, каждая фаза оставляет
> приложение полностью рабочим.

---

## 0. Принятые продуктовые решения (не обсуждаются в рамках плана)

1. Стек остаётся **PyQt6**; редизайн внутри существующей архитектуры
   (панели/воркеры переиспользуются).
2. Ежедневный сценарий: *видео → транскрипт → YouTube-пакет и/или
   статья/пост* — оба одинаково важны.
3. Автономность через **пресеты пайплайнов** («выбрал файл → выбрал пресет →
   запустил → всё само»). Полный Pipeline Engine — отдельная работа; этот
   план готовит для него UI-каркас и не блокируется им.
4. Три «режима» (Posts/Book/Video) как концепция **упраздняются** — их
   функции становятся пресетами/действиями (STRATEGY.md, решение Р1).

## 1. Целевая информационная архитектура

```
┌──────┬────────────────────────────────────────────────────────┐
│      │  [Зона контента выбранного раздела]                    │
│  Н   │                                                        │
│  А   │  Разделы:                                              │
│  В   │   1. Библиотека  (дефолтный экран)                     │
│  И   │   2. Запись      (детали выбранной записи + результаты)│
│  Г   │   3. Очередь     (пакетная обработка)                  │
│  А   │   4. Настройки   (диалог, не раздел)                   │
│      │                                                        │
├──────┴────────────────────────────────────────────────────────┤
│  Статус-бар: текущая операция · прогресс · Отмена             │
└────────────────────────────────────────────────────────────────┘
```

### 1.1. Навигация: узкий сайдбар вместо восьми вкладок

Вертикальный сайдбар слева, ширина 56 px, только иконки с тултипами
(иконки уже есть в `ui/icons.py`):

- **Библиотека** (`history`) — главный экран, открывается при старте.
- **Очередь** (`layers`) — пакетная обработка (бывшая BatchPanel).
- **Диктофон** (`microphone`) — запись с микрофона (бывший RecorderWidget).
- Разделитель, прижато к низу:
- **Настройки** (`gear`) — открывает существующий SettingsDialog.

Экран **Запись** не является пунктом сайдбара — он открывается кликом по
записи в Библиотеке или автоматически по завершении обработки нового файла.

### 1.2. Экран «Библиотека» (первый экран)

```
┌────────────────────────────────────────────────────────────┐
│  ┌──────────────────────────────────────────────────────┐  │
│  │   ⬇  Перетащите аудио/видео или нажмите «Выбрать»    │  │
│  │      [Выбрать файл]   Пресет: [YouTube-пакет ▾] [▶]  │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                            │
│  Поиск: [____________________]                    [RU ▾]   │
│                                                            │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 🎬 С Валерией Ворониной         31:21  вчера         │  │
│  │    ✓ транскрипт  ✓ YouTube  ○ статья                 │  │
│  ├──────────────────────────────────────────────────────┤  │
│  │ 🎙 audio1170954204               48:41  8 июл        │  │
│  │    ✓ транскрипт                                      │  │
│  └──────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────┘
```

- Верх — **дроп-зона + строка запуска**: файл, комбо пресета, большая
  кнопка «Обработать». Это и есть «одна кнопка» ежедневного сценария.
  Дроп файла на любом экране приводит сюда (существующий drag&drop
  `MainWindow` переиспользуется).
- Список записей — из `core/history.py` (SQLite + FTS уже готовы):
  имя, длительность, дата, **чипы готовности артефактов** (транскрипт /
  YouTube / статья / субтитры). Клик — экран «Запись».
- Поиск — уже реализованный FTS.
- До появления Pipeline Engine комбо пресета содержит два пункта:
  «Только транскрипция» и «Транскрипция + YouTube-пакет» (реализация —
  §4, Фаза C: последовательный запуск существующих воркеров).

### 1.3. Экран «Запись»

```
┌────────────────────────────────────────────────────────────┐
│  ← Библиотека   С Валерией Ворониной         [Экспорт ▾]   │
│  ▶─────────────●──────────────────────────  21:05 / 31:21  │
│                                                            │
│  Транскрипт │ Текст │ Статьи │ YouTube │ Инсайты │ Чат │ ✂ │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  (контент активной вкладки; существующие панели      │  │
│  │   переиспользуются как есть)                         │  │
│  └──────────────────────────────────────────────────────┘  │
│  [⚡ Сгенерировать: YouTube-пакет · Статью · Инсайты]      │
└────────────────────────────────────────────────────────────┘
```

- Плеер (`PlayerWidget`) сверху, транскрипт синхронизирован — уже работает.
- Вкладки результата — **существующие** панели (TranscriptView,
  CleanedTextView, ArticleView, YouTubePanel, InsightsPanel, ChatPanel,
  CutView), но теперь они принадлежат записи, а не глобальному окну.
- Кнопка «Экспорт» — **выпадающее меню** с форматами (заменяет 7 вечных
  чекбоксов; выбранные форматы запоминаются в конфиге — поля
  `batch_auto_export`-стиля уже есть, добавь `export_formats: list`).
- Строка «Сгенерировать…» — быстрые действия для уже открытой записи
  (то, что сейчас размазано по AIPanel/YouTube-вкладке/BookPanel).

### 1.4. Куда деваются текущие контролы шапки

| Контрол сейчас | Куда переезжает |
|---|---|
| Модель whisper, Язык, →EN, Производительность, Спикеры | Поповер «Параметры транскрипции» (кнопка-шестерёнка **на строке запуска** в Библиотеке; текущие значения показываются рядом компактной строкой: `large-v3-turbo · авто · 🔋`) |
| GPU/CPU-бейдж | Статус-бар (клик — переключение, как сейчас) |
| Режим Posts/Book/Video | Удаляется (см. §0.4). Книжный пайплайн = действие «Сгенерировать → Книга» на экране Записи |
| Кнопка записи с микрофона | Раздел «Диктофон» в сайдбаре |
| Чекбоксы 7 форматов экспорта | Меню «Экспорт» на экране Записи |
| Кнопка «Транскрибировать» | Кнопка «Обработать» строки запуска |
| Настройки ⚙ | Низ сайдбара |

Принцип: **на первом экране остаётся только то, что нужно в каждом
прогоне** (файл, пресет, запуск, библиотека). Всё остальное — максимум
один клик от первого экрана (поповер/меню/диалог), ничего не глубже.

## 2. Визуальная система

### 2.1. Дизайн-токены — единственный источник стиля

`ui/theme.py` уже содержит `Theme`-датакласс и `build_stylesheet`. Ревизия
нашла **80 инлайн `setStyleSheet` с hex-цветами** в `ui/*.py` — они
дрейфуют от темы и ломают светлую тему.

Правила фазы очистки:
- Ни одного цветового литерала вне `theme.py`. Инлайн-стили заменяются на
  `setProperty("variant", ...)` / `setProperty("role", ...)` + селекторы
  `QPushButton[variant="primary"]`, `QLabel[role="muted"]` и т.п. в
  `build_stylesheet` (паттерн `variant` уже используется — расширь его).
- Роли, которых не хватает: `muted` (серые подписи), `card` (панельки с
  фоном/скруглением), `accent-badge` (бейджи устройства), `danger`.
- Отступы — только из шкалы: 4 / 8 / 12 / 16 / 24 (уже фактически так,
  зафиксируй константами `SPACING_*` в theme.py).
- Радиусы: 6 (контролы), 10 (карточки). Шрифты: системный; размеры 11/13/15/18.

### 2.2. Современность без экзотики

- Больше воздуха: `setContentsMargins(24, 20, 24, 24)` на корневых экранах.
- Карточки списка Библиотеки — `QListView` + кастомный delegate (не таблица).
- Тонкие разделители `#333`-токеном, без рамок-коробок вокруг всего.
- Кнопка «Обработать» — крупная (высота 36+), primary-вариант, с иконкой.
- Статусы-чипы артефактов — маленькие скруглённые лейблы role="chip".
- Тёмная тема — дефолт (как сейчас); светлая обязана не ломаться
  (проверка обеих — в приёмке каждой фазы).

## 3. Технический каркас

### 3.1. Новые файлы

```
ui/sidebar.py          — вертикальная навигация (QFrame + QToolButton'ы,
                         checkable, exclusive; сигнал section_changed(str))
ui/library_view.py     — экран Библиотеки: дроп-зона, строка запуска,
                         поиск, список записей (модель поверх history)
ui/record_view.py      — экран Записи: заголовок, плеер, вкладки
                         результатов, строка «Сгенерировать»
ui/launch_bar.py       — строка запуска (файл + пресет + параметры +
                         Обработать); переиспользуется Библиотекой
ui/transcribe_options.py — поповер параметров транскрипции (модель, язык,
                         →EN, производительность, диаризация)
```

`MainWindow` становится тонким: сайдбар + `QStackedWidget`
(library_view / record_view / batch_panel / recorder-раздел) + статус-бар.
Вся логика запуска транскрипции/воркеров **остаётся в MainWindow** (или
выносится в `ui/controller.py`, если при работе станет видно, что окно
похудеет недостаточно) — панели общаются с ней сигналами, как сейчас.

### 3.2. Что переиспользуется без переписывания

`TranscriptView`, `CleanedTextView`, `ArticleView`, `ChatPanel`,
`InsightsPanel`, `YouTubePanel`, `CutView`, `PlayerWidget`,
`RecorderWidget`, `BatchPanel`, `SettingsDialog`, `ProviderDialog`,
вся `core/*` и движки. Меняется только их **компоновка и точки входа**.

### 3.3. Конфиг

Новые поля `Config` (все с дефолтами, старые конфиги живы):
```python
export_formats: list = field(default_factory=lambda: ["txt"])
last_preset: str = "transcribe"      # id пресета в строке запуска
# pipeline_mode: str — пометить deprecated, не читать в UI (удалить поле
# нельзя — сломает load старых конфигов? Нет: load фильтрует по known
# fields, так что поле можно удалить после одного релиза. В этом плане —
# просто перестать использовать.)
```

## 4. Фазы выполнения

Каждая фаза = серия мелких коммитов; после каждой фазы приложение полностью
рабочее, `ruff` чистый, pytest зелёный, headless-смоук проходит, обе темы
не сломаны. UI-строки — только через `tr()`, ключи добавлять в **оба**
`locales/*.json` синхронно.

### Фаза A — фундамент стиля (низкий риск)

1. `refactor: add spacing/role tokens to theme` — SPACING-константы, роли
   `muted/chip/card/danger` в `build_stylesheet`.
2. `refactor: replace inline hex styles with theme roles (ui/main_window)` —
   убрать все `setStyleSheet` с литералами из main_window (бейдж устройства,
   заголовки, action bar…).
3. `refactor: replace inline hex styles with theme roles (panels)` — то же
   для youtube_panel, insights_panel, chat_panel, book_panel и остальных
   (найди все: `grep -n 'setStyleSheet' ui/*.py`).
4. Приёмка фазы: `grep -cE '#[0-9a-fA-F]{3,6}' ui/*.py` = 0 вне theme.py;
   визуально ничего не деградировало (скриншоты до/после в обеих темах).

### Фаза B — новая навигация (каркас)

1. `feat: add sidebar navigation` — `ui/sidebar.py`, `QStackedWidget` в
   MainWindow; страницы: «Библиотека» (пока = старый центральный layout
   как есть), «Очередь» (BatchPanel), «Диктофон» (RecorderWidget крупно),
   Настройки — кнопка-диалог.
2. `feat: add library view with search and record cards` —
   `ui/library_view.py` поверх `core/history.py`; чипы артефактов пока по
   наличию транскрипта (расширение — Фаза D). Открытие записи → сигнал
   `open_record(id)` → существующий `_load_from_history`.
3. `feat: add record view hosting result tabs` — `ui/record_view.py`;
   перенос вкладок из глобального QTabWidget; кнопка «← Библиотека»;
   заголовок = имя записи. History-вкладка из набора вкладок удаляется
   (её заменила Библиотека).
4. `feat: move export to dropdown menu on record view` — QMenu с
   чекабельными форматами (`export_formats` в конфиге), пункт
   «Экспортировать» внизу меню; удалить чекбоксы из левой колонки.
5. `refactor: retire mode switcher` — убрать mode_combo; BookPanel-функции
   доступны кнопкой «Сгенерировать → Книга» на экране Записи; VideoPanel-
   действия (EDL, паузы, черновик) — внутри вкладки «✂ Нарезка» (CutView),
   к которой они и относятся.
6. Приёмка фазы: старт приложения → Библиотека; открытие записи из истории
   → экран Записи со всеми вкладками; все прежние функции достижимы; смоук
   и тесты зелёные.

### Фаза C — строка запуска и мини-пайплайн (сердце ежедневного сценария)

1. `feat: add launch bar with preset combo` — `ui/launch_bar.py` в
   Библиотеке: файл (перетаскивание/кнопка), комбо пресетов
   («Только транскрипция», «Транскрипция + YouTube-пакет»,
   «Транскрипция + Статья», «Полный пакет»), кнопка «Обработать»,
   кнопка-шестерёнка параметров.
2. `feat: add transcribe options popover` — `ui/transcribe_options.py`
   (модель/язык/→EN/производительность/диаризация из шапки); рядом с
   шестерёнкой — компактная сводка текущих значений.
3. `feat: chain generation steps after transcription per preset` —
   мини-оркестрация в MainWindow/контроллере: по `_on_finished`
   транскрипции, если пресет требует, автоматически запустить
   YouTube-генерацию (`youtube_panel._generate()` — вынеси в публичный
   `generate()`), чистку+статью (`AIProcessingWorker`), по завершении —
   автосохранить результаты файлами в `data_dir()/output/<стем-записи>/`
   и показать тост «Готово: N артефактов». Отмена (статус-бар) отменяет
   всю цепочку. Ошибки шагов видимы (паттерн F7 из SONNET_FIXES_PLAN).
4. `feat: persist generated artifacts to history record` — при сохранении
   артефактов писать их пути/типы в history-запись (расширь схему таблицы
   миграцией `ALTER TABLE … ADD COLUMN artifacts TEXT` с дефолтом NULL);
   чипы Библиотеки читают это поле.
5. Приёмка фазы (сквозной сценарий): бросить видео в окно → выбрать
   «Транскрипция + YouTube-пакет» → «Обработать» → не трогать мышь до
   тоста → в Библиотеке у записи чипы «транскрипт, YouTube», на диске
   папка с файлами, вкладки Записи заполнены. Пресет и параметры пережили
   перезапуск приложения.

### Фаза D — полировка

1. Статус-бар: текущий шаг цепочки + общий прогресс + Отмена + GPU-бейдж.
2. Горячие клавиши обновить под новую навигацию (`Ctrl+1..4` — разделы,
   `Ctrl+O` — файл, `Ctrl+Enter` — Обработать); существующий хелпер `_sc`.
3. Пустые состояния: Библиотека без записей — дружелюбная подсказка с
   иконкой; вкладки без результата — кнопка «Сгенерировать» по месту.
4. Тултипы и локализация всех новых строк (en+ru), проверка светлой темы.
5. Приёмка: чек-лист §5 целиком.

## 6. Чего НЕ делать

- Не переписывать воркеры/движки и `core/*` — только UI-слой и тонкая
  оркестрация сигналов (исключение: публичный `generate()` у YouTubePanel
  и миграция схемы истории, описанные выше).
- Не строить полный Pipeline Engine (декларативные шаги, свои промпты,
