# Whispered: перспективы развития и применения

> Дата: 2026-07-06. Дополняет `ROADMAP.md` (номера задач N.M ниже — по полной версии в `archive/ROADMAP_full_2026-07.md`) и
> `AUDIT_HANDOFF.md` (качество). Здесь — стратегические направления: куда
> продукт может вырасти и кому он нужен.

## 1. Позиционирование

Whispered занимает нишу **«приватный Descript/MacWhisper для Linux и не только»**:
полностью офлайн пайплайн «аудио/видео → транскрипт → готовый контент».
Конкуренты либо облачные (Descript, Otter, Rev), либо только-транскрипция
(MacWhisper, superwhisper), либо только-macOS. Уникальное сочетание:

1. Офлайн end-to-end, включая LLM-этап (LM Studio).
2. Linux как первоклассная платформа (AppImage, ROCm).
3. Не просто транскрипт, а контент-фабрика: статьи, книги, YouTube-метаданные,
   монтаж видео по тексту.

## 2. Направления развития продукта

### 2.1. Ближний горизонт (усиление ядра)

- **Live-транскрипция и режим диктовки** (ROADMAP 3.2, 4.1) — превращает
  приложение из «обработчика файлов» в ежедневный инструмент; глобальный
  хоткей как у superwhisper — самая частая причина покупки таких утилит.
- **Захват системного звука** (ROADMAP 4.2) — транскрипция Zoom/Meet-звонков
  без ботов-участников; на фоне ужесточения политик приватности встреч это
  сильный аргумент.
- **Word-level таймстампы + караоке-подсветка** (ROADMAP 4.5) — фундамент для
  редактирования видео по тексту (см. 2.2) и точных субтитров.
- **Watch-папка и CLI** (ROADMAP 4.4) — встраивание в чужие пайплайны;
  CLI-режим открывает headless-применения на серверах.

### 2.2. Средний горизонт (новые ценностные контуры)

- **Text-based video editing как флагман.** Уже есть `video_edit.py`,
  `timeline_export.py`, cut_view. Довести до «удалил предложение — вырезался
  фрагмент видео» + экспорт EDL/FCPXML/OTIO в DaVinci/Premiere/CapCut. Это
  фича уровня Descript, которой нет ни у одного офлайн-инструмента.
- **Расширение LLM-бэкендов.** Сейчас только LM Studio. Добавить Ollama и
  llama.cpp-server (все OpenAI-совместимы — изменение почти только в
  настройках и автодетекте), опционально — облачные API за явным
  переключателем «privacy off». Снимает зависимость от одного стороннего
  приложения.
- **Библиотека промптов как экосистема** (ROADMAP 4.3): промпты уже в
  `prompts/*.md` — дать пользователю редактор, импорт/экспорт пресетов,
  каталог сообщества. Дешёвый способ получить контрибьюторов.
- **Субтитровая студия**: перевод транскрипта (ROADMAP 3.8) + стилизация +
  burn-in через ffmpeg = локализация роликов одним инструментом.
- **Плагинная архитектура экспортёров**: `exporters.py` уже модульный; дать
  точку расширения (entry points) для сторонних форматов и CMS
  (WordPress, Ghost, Telegram-каналы уже упомянуты в README).

### 2.3. Дальний горизонт

- **Meeting-ассистент**: календарная интеграция, автозапись, саммари и
  action items (`prompts/action_items.md` уже есть) в Obsidian/Markdown-вольт.
- **Локальный семантический поиск по архиву**: эмбеддинги по истории
  транскрипций (история и FTS уже в ROADMAP 3.6) — «найди, где мы обсуждали
  бюджет» по всем записям, офлайн.
- **Мультиязычный книжный конвейер**: `book_pipeline.py` → «наговорил книгу
  голосом» как отдельный продуктовый сценарий с собственным лендингом.

## 3. Сферы применения

| Сегмент | Сценарий | Почему Whispered |
|---|---|---|
| Подкастеры, YouTube | Транскрипт → главы, описание, теги, посты, шортсы | YouTube-пайплайн уже реализован; нет платы за минуты |
| Журналисты | Интервью → расшифровка с диаризацией → статья | Источники не уходят в облако |
| Юристы, медицина, госсектор | Диктовка и расшифровка конфиденциальных записей | Офлайн — единственный допустимый режим; on-prem без лицензий на API |
| Корпорации (on-prem) | Протоколы встреч, база знаний из звонков | CLI/watch-папка + локальный LLM на сервере компании |
| Образование | Лекции → конспекты, FAQ, глоссарии | Батч-обработка семестра записей за ночь |
| Авторы книг | Надиктовка → структурированная рукопись | Уникальный book pipeline |
| Разработчики | Голосовые заметки → тикеты, документация | Режим диктовки + пользовательские промпты |
| Доступность | Субтитры для слабослышащих, конспекты для дислексиков | Бесплатно, локально, любой язык whisper |

## 4. Модели распространения и монетизации

- **Open-core**: ядро свободное (текущий код), Pro-надстройки платные —
  системный звук, live-режим, видеоредактор, приоритетная поддержка.
  Прецеденты: MacWhisper (единоразовая покупка), superwhisper (подписка).
- **Каналы**: Flathub (главный для Linux-аудитории; metainfo.xml уже готов),
  Homebrew cask для macOS, позже — Microsoft Store. Публикация на Flathub —
  самый дешёвый следующий шаг к дистрибуции.
- **B2B on-prem**: лицензия для организаций с требованиями к данным
  (медицина, юриспруденция, госструктуры) — там, где облачные конкуренты
  дисквалифицированы по определению.
- **Сообщество**: каталог промпт-пресетов и экспорт-плагинов как драйвер
  органического роста; хорошие first-issue задачи уже есть в ROADMAP.

## 5. Риски и что с ними делать

| Риск | Митигация |
|---|---|
| Зависимость от LM Studio (сторонний закрытый продукт) | Поддержка Ollama/llama.cpp (см. 2.2) |
| Качество локальных LLM ниже облачных для «книжных» задач | Честные пресеты «что реально работает на 7B/14B»; опциональный облачный режим с явным согласием |
| Ресурсоёмкость (whisper large + LLM одновременно) | Профили производительности уже есть; добавить автоподбор моделей под железо |
| Один мейнтейнер, широкий фронт функций | AUDIT_HANDOFF.md: сначала гигиена и тесты, потом новые фичи; ROADMAP уже дисциплинирует агентов |
| Конкуренты добавят офлайн-режим | Скорость выхода text-based video editing — главный защитный ров |

## 6. Рекомендуемая последовательность (стратегически)

1. **Гигиена** — выполнить план `AUDIT_HANDOFF.md` (низкий риск, повышает
   скорость всего дальнейшего).
2. **Дистрибуция** — Flathub-публикация: рост аудитории без новых фич.
3. **Ежедневная ценность** — глобальный хоткей + диктовка + live-режим
   (превращает «иногда-инструмент» в «всегда-инструмент»).
4. **Ров** — text-based video editing + экспорт в NLE.
5. **Монетизация** — Pro-tier поверх выросшей базы пользователей.
