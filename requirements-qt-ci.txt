# Dependencies for the real-Qt smoke suite (tests_qt/) in CI.
#
# Deliberately NOT requirements-dev.lock: that pins pywhispercpp, which
# publishes no manylinux wheel for the pinned version and would make every
# CI run compile whisper.cpp from source. The engine is imported lazily
# (transcriber.py resolves pywhispercpp inside the child process), so the
# UI layer constructs fine without it — which is exactly what this suite
# checks. sounddevice is lazy for the same reason and also omitted.
#
# Versions mirror requirements.lock; keep them in step when that is
# regenerated.
# This suite uses the supported runtime interpreter, CPython 3.11.
