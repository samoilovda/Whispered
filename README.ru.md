## Зачем

Облачные сервисы транскрипции берут подписку, загружают ваши исходники на
чужие серверы и режут длинные файлы лимитами. Whispered выполняет весь
конвейер локально: `whisper.cpp` для распознавания речи (ускорение Metal /
CUDA / ROCm), `pyannote.audio` для диаризации спикеров и любая локальная LLM
через LM Studio для генерации контента. Ваши данные остаются вашими.

## Возможности

- **Транскрипция** — `whisper.cpp` с аппаратным ускорением, выбор модели
  (tiny → large-v3-turbo), 99 языков, перевод на английский,
  пользовательский словарь.
- **Диаризация** — метки «кто что сказал» через `pyannote.audio`,
  переименование спикеров.
- **Пресеты в один клик** — *Транскрипция*, *+ YouTube-пакет*, *+ Статья*,
  *Всё сразу*: выбрали файл, нажали Process, забрали артефакты.
- **YouTube-пакет** — 5 вариантов заголовка, описание с хуком, тайм-коды
  глав (зрительские, разрыв не больше 7,5 минут), тайм-коды ключевых
  вопросов и теги — локальная LLM работает по полному транскрипту.
- **Генерация контента** — статьи в 5 форматах (блог, FAQ, листикл, саммари,
  посты для соцсетей), чистка транскрипта, AI-чат с транскриптом, инсайты
  (главы / задачи / ключевые моменты).
- **Библиотека** — каждая транскрипция сохраняется автоматически,
  полнотекстовый поиск (SQLite FTS5), любую запись можно открыть заново со
  всеми артефактами.
- **Запись и очередь** — запись с микрофона, пакетная обработка папки.
- **Вкладка Cut** — отметьте сегменты галочками и экспортируйте
  EDL-таймлайн для видеоредактора.
- **Экспорт** — TXT, TXT с тайм-кодами, SRT, VTT, JSON, Markdown, HTML,
  DOCX, PDF.
- **Интерфейс** — тёмная/светлая темы, локализация RU/EN, drag-and-drop.

Единственные необязательные сетевые вызовы: скачивание моделей по вашему
явному действию и облачный API-ключ для одной функции вкладки YouTube
(по умолчанию выключено — стандартный путь полностью локальный).

## Как это работает

```
медиафайл ──▶ ffmpeg ──▶ whisper.cpp (отдельный процесс, отменяемый)
                             │
                             ▼
                    транскрипт + спикеры (pyannote)
                             │
                             ▼
              локальная LLM через LM Studio (OpenAI-совместимый API)
                             │
                             ▼
        YouTube-пакет · статьи · инсайты · очищенный текст
```

| Слой | Модули |
|---|---|
| UI (PyQt6) | `ui/` — главное окно, библиотека, launch bar, вкладки результатов |
| Воркеры | `core/` — QThread-воркеры, клиент LM Studio, история, i18n |
| Движки | `transcriber.py`, `diarizer.py`, `article_generator.py`, `text_processor.py` |
| Промпты | `prompts/*.md` — каждая LLM-задача описана редактируемым Markdown-промптом |

Транскрипция идёт в отдельном **процессе** (жёсткая отмена, никакой борьбы
за GIL); вся LLM/IO-работа — в **QThread**: интерфейс никогда не блокируется.

## Быстрый старт

**Fedora / Linux**

```bash
./setup.sh   # ставит зависимости, собирает whisper.cpp, качает модель
./run.sh
```

**macOS**

```bash
./setup-mac.sh
./run-mac.sh
```

Автономный `Whispered.app` собирается командой `.venv/bin/python build.py`;
AppImage — `appimage/build-appimage.sh`.

Для AI-функций установите [LM Studio](https://lmstudio.ai), загрузите любую
чат-модель и запустите локальный сервер (`lms server start`) — Whispered
подхватит его автоматически. Всё остальное (транскрипция, диаризация,
экспорт) работает и без него. Windows пока не поддерживается — см.
[roadmap](ROADMAP.md).

## Разработка

```bash
pip install -r requirements.txt -r requirements-dev.txt
ruff check .                 # линтер — должен быть чистым
python -m pytest tests/ -q   # 292 юнит-теста, Qt полностью застаблен
python main.py               # запуск из исходников
```

Конвенции тестов — в [TESTING.md](TESTING.md); правила проекта, которым
следуют и люди, и ИИ-агенты — в [CLAUDE.md](CLAUDE.md).

Проект разрабатывается AI-first: код пишется в связке с ИИ-агентами по
самодостаточным техзаданиям (выполненные планы — в `docs/archive/`), с
жёсткими воротами перед каждым коммитом: линтер + тесты + headless
смоук-проверка UI.
