Загрузите часовое интервью и получите: транскрипт с метками спикеров,
готовый YouTube-пакет (5 вариантов заголовка, описание с хуком,

статей в пяти форматах, инсайты, черновик книги и EDL-таймлайн для
монтажа. Всё работает локально — аудио не покидает машину, LLM локальная
(LM Studio), облако — опция на вашем ключе.

## Почему не MacWhisper / Whisper Transcription / аналоги?

Те инструменты делают транскрипцию отлично. Whispered делает транскрипцию
**и продолжает дальше**: транскрипт превращается в YouTube-пакет, пять
форматов статей, инсайты, книжный пайплайн и EDL-таймлайн — за один
прогон, одним нажатием пресета. Вторая ось — локальность: никакой
подписки, никакой загрузки, никаких лимитов. Нативный стек whisper.cpp
живёт вне бандла, так что Metal-сборку можно обновить без пересборки
приложения.

## Функциональность

### Библиотека
Каждая транскрипция автосохраняется в SQLite с полнотекстовым поиском
(FTS5). Любую запись можно открыть заново со всеми артефактами. Пресеты в
один клик запускают весь конвейер: выбрали файл, нажали *Всё сразу* —
забрали результаты.

### Очередь и запись
Пакетная обработка папки или запись прямо с микрофона — оба источника
проходят через тот же конвейер.

### Просмотр транскрипта
Встроенный аудио/видеоплеер, синхронизированный с транскриптом. Метки
спикеров от `pyannote.audio`, переименование прямо в интерфейсе. 9
форматов экспорта: TXT, TXT с тайм-кодами, SRT, VTT, JSON, Markdown,
HTML, DOCX, PDF.

### YouTube-пакет
5 вариантов заголовка, описание с хуком, зрительские тайм-коды глав
(разрыв ≤ 7,5 мин), тайм-коды ключевых вопросов и теги — локальная LLM
работает по полному транскрипту. Опциональный облачный провайдер (ваш
ключ) на той же вкладке.

### Инструменты контента
- **Статьи** — блог-пост, FAQ, листикл, саммари, посты для соцсетей
- **Чат** — вопросы по транскрипту
- **Инсайты** — авто-главы, задачи, ключевые моменты
- **Книжный пайплайн** — черновик из любой длинной записи
- **Cut / EDL** — галочки на сегментах, экспорт таймлайна для монтажёра
- **Чистка транскрипта** — убираем слова-паразиты и повторы через LLM

### Интерфейс
Тёмная / светлая темы, локализация RU / EN, drag-and-drop, анимированная
шкала прогресса, тост-уведомления.

## Архитектурные решения

Четыре решения, которые определили форму кодовой базы — не каталог фич.

**Транскрипция в дочернем процессе, а не потоке.**
`whisper.cpp` — C-расширение; кооперативная отмена через `threading.Event`
не прерывает выполняющийся C-вызов. Решение: запускаем отдельный процесс
через `multiprocessing.get_context('spawn')`, передаём прогресс через
`Queue`, при отмене делаем `terminate()` / `kill()`. Кнопка «Отмена»
действительно отменяет.

**Единственный узкий контракт: `Segment(start, end, text, speaker)`.**
Все потребители — плеер, экспортёры, каждый LLM-промпт — получают список
объектов `Segment`. Движок транскрипции спрятан за этим контрактом.
Замена whisper.cpp на другой движок (Parakeet, GigaAM) — это изменение
одного импорта; остальной код не трогается.

**Нативный стек живёт вне бандла.**
`~/Library/Application Support/Whispered/lib` хранит pywhispercpp и
Metal-скомпилированные dylib. Обновить сборку whisper.cpp или переключиться
CPU → Metal можно без пересборки `Whispered.app`.

**17 промптов в Markdown, ноль промптов в Python.**
Каждая LLM-задача (`yt_titles.md`, `chapters.md`, `blog_post.md`, …) —
отдельный Markdown-файл, загружаемый в рантайме через
`core.prompts.load_prompt`. Перефразировать промпт, добавить языковое
ограничение, протестировать тон — это правка текстового файла без
единого изменения кода.

## Честные ограничения

- **Движок:** транскрипция только через whisper.cpp. Архитектура
  движконезависима (контракт `Segment`), но альтернативные бэкенды пока
  не поставляются.
- **LM Studio и параллельные запросы:** одновременные длинные LLM-задачи
  могут подвесить сервер. Конвейер инсайтов уже обходит это через
  последовательные запросы; остальные вкладки — пока нет. Обходной путь:
  `lms server stop && lms server start`.
- **Платформы:** macOS — основная цель (Metal, сборка `.app`). Linux
  AppImage работает, но менее обкатан. Windows пока не поддерживается —
  см. [ROADMAP.md](ROADMAP.md).
- **Корректность UI:** покрыта 292 юнит-тестами + headless смоук-проверкой
  (нет краша). Пиксельная точность вёрстки проверяется вручную.

## Быстрый старт

**macOS**

```bash
./setup-mac.sh   # собираем whisper.cpp с Metal, качаем базовую модель
./run-mac.sh
```

**Linux (Fedora / Ubuntu)**

```bash
./setup.sh       # собираем whisper.cpp (CUDA / CPU), качаем базовую модель
./run.sh
```

Собрать автономный `.app`:

```bash
.venv/bin/python build.py
```

Собрать Linux AppImage:

```bash
appimage/build-appimage.sh
```

Для AI-функций установите [LM Studio](https://lmstudio.ai), загрузите любую
чат-модель и запустите локальный сервер (`lms server start`) — Whispered
подхватит его автоматически. Транскрипция, диаризация и экспорт работают
и без него.

## Разработка

```bash
pip install -r requirements.txt -r requirements-dev.txt
ruff check .                   # должен быть чистым
python -m pytest tests/ -q     # 292 теста, Qt застаблен — дисплей не нужен
python main.py                 # запуск из исходников
```

Конвенции тестов — в [TESTING.md](TESTING.md); правила проекта, которым
следуют и люди, и ИИ-агенты — в [CLAUDE.md](CLAUDE.md).

**Модель разработки:** AI-assisted, owner-operated. Код пишется в связке
с ИИ-агентами по самодостаточным спецификациям (выполненные планы — в
`docs/archive/`). Жёсткий гейт перед каждым коммитом: ruff + pytest +
headless смоук-проверка UI.
