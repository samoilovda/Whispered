**Локальная транскрипция аудио и видео с инструментами для дальнейшей работы
с материалом.**

Whispered — настольное приложение на PyQt6. Оно транскрибирует записи через
`whisper.cpp`, при необходимости размечает спикеров через `pyannote.audio`,
хранит историю с поиском и выполняет *рецепты* — именованные наборы шагов,
которые превращают транскрипт в очищенный текст, статью, инсайты,
YouTube-пакет, книжный черновик или обложку, а также в субтитры и монтажный
таймлайн.

Транскрипция выполняется локально. AI-функции по умолчанию используют локальный
сервер LM Studio. Отправка текста во внешний сервис происходит только при
явном выборе облачного провайдера на вкладке YouTube.

## Как это работает

Окно — двухколоночное рабочее пространство: слева **Библиотека**
(сворачивается, на узких окнах — автоматически), справа текущий документ:
стартовый экран, запись, рабочее пространство обложек или экран прогона.
Расположение панелей запоминается между запусками.

1. **Стартовый экран.** Выберите источник — файл, папку, микрофон или Live —
   и рецепт, затем запустите одной кнопкой. Параметры транскрипции спрятаны за
   строкой сводки и ссылкой «Изменить».
2. **Экран прогона.** Рецепт выполняется как один прогон: по строке на шаг
   (расшифровка, диаризация, очистка, статья, инсайты, YouTube-пакет, книга,
   обложка), живой прогресс, общий индикатор с прошедшим временем и оценкой
   оставшегося (после двух завершённых шагов), точечный перезапуск/отмена без
   повторного выполнения уже сделанного. Шаг, у которого не изменились входные
   данные (транскрипт, модель, промпт), пропускается по кешу.
3. **Запись.** После расшифровки открывается запись с плеером и вкладками:
   Транскрипт, Очищенный текст, Статьи, YouTube, Книга, Инсайты, Cut и Chat.
   Обложки открываются кнопкой **Cover** в шапке записи, через
   **Go → Covers** (`Ctrl+4`) или из Библиотеки.

Остальные элементы интерфейса:

- `Ctrl+K` открывает командную палитру: поиск по истории транскриптов и
  сгенерированным материалам, все рецепты («Запустить: <рецепт>»),
  провалившиеся/отменённые шаги открытого прогона («Перезапустить: <шаг>») и
  все пункты меню.
- Единый статус-бар показывает текущую операцию и прогресс, отмену,
  всплывающую очередь пакетных задач и Course Capture, а также статус
  LM Studio/GPU.
- Тёмная/светлая тема и интерфейс на русском или английском; язык
  переключается на лету, без перезапуска.

## Что умеет приложение

### Рецепты

Рецепт — именованный список шагов из набора `transcribe`, `diarize`, `clean`,
`article`, `insights`, `youtube_package`, `book`, `cover`. Пять рецептов
встроены:

| Рецепт | Шаги |
|---|---|
| Только расшифровка | transcribe |
| Видео на YouTube | transcribe → clean → YouTube-пакет → обложка |
| Статья из подкаста | transcribe → clean → статья |
| Заметки со встречи | transcribe → diarize → инсайты |
| Книга | transcribe → clean → книга |

**«Настроить…»** открывает редактор рецептов, где можно сохранять свои
(Save / Save as new / Delete). Пользовательский рецепт появляется рядом со
встроенными на стартовом экране и как фильтр в Библиотеке и может нести свои
модель, язык, перевод, режим производительности и диаризацию; всё, что не
задано, берётся из общих настроек.

Прогоны сохраняются для каждой записи. Карточка в Библиотеке показывает
провалившиеся шаги, не открывая запись, а прогон, который упал, был отменён
или прерван закрытием приложения, можно возобновить кнопкой **«Продолжить»** —
уже успешные шаги не повторяются.

Транскрипция и сохранение в историю выполняются всегда. Монтажные операции
(Cut) запускаются вручную.

Источник **«Папка»** ставит файлы в очередь только на расшифровку; остальные
шаги выбранного рецепта к файлам очереди не применяются.

### Транскрипция

- аудио: MP3, WAV, FLAC, M4A, OGG, OPUS, WMA, AAC;
- видео: MP4, MKV, AVI, MOV, WebM, WMV, FLV, M4V;
- восемь моделей Whisper — Tiny, Base, Small, Medium, Large v3, Turbo и
  квантизации Turbo Q5 / Q8 — загружаются по требованию, в списке моделей
  отмечены уже скачанные;
- автоопределение языка, выбор одного из 19 языков и перевод речи на английский;
- профили Efficiency / Balanced / Performance и ускорение CPU / Metal / CUDA /
  ROCm;
- пользовательский словарь, передаваемый Whisper как initial prompt;
- реальная отмена: движок запускается в отдельном процессе, который можно
  завершить, не закрывая приложение.

Для преобразования медиафайлов, определения длительности, кадров для обложек и
видеомонтажа нужны `ffmpeg` и `ffprobe`.

### Спикеры

Опциональная диаризация через `pyannote.audio` добавляет метки спикеров.
Спикеров можно переименовывать и объединять; имена сохраняются в истории и
используются при экспорте. Ранее введённые имена предлагаются подсказками при
переименовании в других записях. Это список подсказок, а не распознавание
спикеров: «SPEAKER_00» в двух файлах — разные объекты.

### Библиотека, очередь и запись

- SQLite-история с полнотекстовым поиском FTS5 и запасным поиском через `LIKE`;
- переключатель области поиска: **Транскрипты**, **Материалы** (текст
  сгенерированных статей, инсайтов, YouTube-пакетов и книг) или **Всё**;
  результат по материалам открывает запись на вкладке, которая его создала.
  Записи, сделанные до появления этой функции, можно проиндексировать
  действием **Reindex materials** в настройках;
- фильтры по источнику и по рецепту со сбросом;
- повторное открытие сегментов, метаданных и имён спикеров;
- пакетная очередь: перетащите на окно несколько файлов (или папку — она
  раскрывается на один уровень) либо добавьте файлы в панели очереди; они
  расшифровываются последовательно и сохраняются в историю;
- **watch-папка** (Настройки → General, по умолчанию выключена): новые
  поддерживаемые файлы в локальной папке автоматически попадают в очередь, как
  только перестают расти;
- запись с микрофона с выбором устройства, индикатором уровня, паузой и
  продолжением.

История хранит транскрипты, состояние прогонов и искомый текст сгенерированных
материалов, но сама не возвращает содержимое ранее созданных AI-артефактов в их
панели. Результаты рецепта сохраняются отдельными файлами в каталоге данных
приложения, у каждого есть манифест происхождения (`<файл>.manifest.json`):
ревизия транскрипта, модель и версия промпта, которые его создали.

### Работа с транскриптом

- встроенный аудио/видеоплеер и переход к позиции по клику на сегмент;
- редактирование сегментов с сохранением тайм-кодов, поиск, замена, копирование;
- **Версии**: каждая правка сохраняется как недеструктивная ревизия (по
  умолчанию хранятся последние 20); любые две можно сравнить с подсвеченным
  diff, любую — восстановить;
- экспорт в 9 форматов: TXT, TXT с тайм-кодами, SRT, VTT, JSON, Markdown, HTML,
  DOCX и PDF;
- **пресеты экспорта** собирают форматы и уже сгенерированные материалы в одну
  папку с `index.txt`: *YouTube* (SRT + VTT + YouTube-пакет + обложка),
  *Черновик статьи* (Markdown + DOCX + статья) и *Архив* (все форматы и все
  материалы). Материал, которого у записи нет, попадает в отчёт, а не считается
  ошибкой.

### AI-инструменты

Для следующих функций нужен запущенный LM Studio с загруженной chat-моделью:

- очистка текста от слов-паразитов и приведение устной речи к связному тексту;
- пять форматов материалов: блог-пост, FAQ, листикл, краткое резюме и посты
  для соцсетей;
- чат с контекстом открытого транскрипта и потоковой выдачей ответа;
- инсайты: главы, задачи и ключевые моменты;
- книжный конвейер: «расшивка» устной речи, дополнительный пользовательский
  промпт и пакетная обработка Markdown-файлов.

YouTube-пакет включает главы с тайм-кодами, варианты заголовков, описание, теги
и ключевые вопросы с тайм-кодами.

Только YouTube-пакет можно генерировать не только через LM Studio, но и через
OpenAI-совместимый API или Anthropic с ключом пользователя. Остальные
AI-инструменты сейчас работают через LM Studio.

Шаблоны задач — редактируемые Markdown-файлы в `prompts/`.

### Генератор обложек

Раздел «Обложки» создаёт YouTube-обложки «Просвета» по встроенному
декларативному шаблону. Доступны раскладки для двух участников, одного участника
и только текста, мятный/тёплый варианты, живое превью, подсказки заголовка из
открытого транскрипта и воспроизводимый экспорт PNG/JPEG с `.cover.json`.
Исходный Templegarten заменён на встроенный Bellota Bold с лицензией OFL и
системным фолбэком. Экспорт Shorts остаётся опцией до бренд-приёмки авторской
адаптации 9:16.

Портреты выбираются из файлов PNG/JPEG или, если открыта видеозапись, берутся
из неё: **«Кадр из видео»** открывает диалог с полем времени (по умолчанию —
позиция плеера) и галереей кадров-кандидатов, которые `ffmpeg` извлекает в
фоне. У каждого слота фото также есть выбор фокусной точки (кадрирования).

Поиск плиток Zoom, ONNX-реставрация лиц и localhost-адаптер ComfyUI существуют
как экспериментальные модули ядра и пока не подключены к рабочему пространству.

### Монтаж

На вкладке Cut можно выбрать сохраняемые сегменты, автоматически снять выбор с
пауз, перейти к нужному месту в плеере, экспортировать CMX3600 EDL и собрать
черновой MP4 через `ffmpeg`. Сборка MP4 по умолчанию перекодирует выбранные
фрагменты для более точных границ.

### Live-транскрипция и Course Capture (экспериментально)

Live включается вручную в настройках, а запускается из выбора источника на
стартовом экране. Реализованы:

- микрофонный и системный источники;
- асинхронная предварительная проверка готовности;
- инкрементальный транскрипт, пауза/продолжение и диагностика;
- сохранение финальных текстовых сегментов в библиотеку во время сессии;
- обнаружение приложений и захват системного аудио через отдельный
  ScreenCaptureKit-helper.

**Course Capture** работает на том же конвейере: заведите очередь именованных
уроков, воспроизводите каждый в браузере или другом приложении, которое вы
смотрите, захватывайте его системное аудио — каждый завершённый урок сохраняется
в Библиотеку как обычная запись. Он отображается вкладкой во всплывающей
очереди статус-бара, когда включён Live. Захватывается только звук; источник
не скачивается и не затрагивается.

Live не пишет WAV, M4A или временный PCM-файл: аудио существует только в
ограниченных буферах памяти, нужных для текущего распознавания. Поэтому
в библиотеке у такой сессии доступен текст и экспорт, но нет плеера и
операций, которым нужен исходный медиафайл.

Захват системного аудио доступен только на macOS 13+ и требует собранного
Swift-helper, а также разрешения Screen Recording. Live остаётся
экспериментальной, выключенной по умолчанию функцией и ещё не прошёл полный
релизный soak-тест.

### Хранение API-ключей

Если установлен необязательный пакет `keyring` и доступен рабочий backend ОС,
API-ключи облачных провайдеров и токен Hugging Face сохраняются в macOS
Keychain, Windows Credential Manager или Linux Secret Service. Иначе
Whispered использует локальный конфигурационный файл с доступом только для
владельца. Используйте отдельный ключ с минимально необходимыми правами.

## Быстрый старт

Требования:

- CPython 3.11;
- `ffmpeg` и `ffprobe`;
- macOS (основная платформа), Linux или Windows 11 x64 в preview-режиме;
- LM Studio — только для AI-функций.

### macOS

```bash
./setup-mac.sh
./run-mac.sh
```

Скрипт `setup-mac.sh` создаёт окружение, собирает `pywhispercpp` с Metal на
Apple Silicon и устанавливает все объявленные runtime-зависимости. Нужную
модель Whispered загружает при первом использовании.

### Linux

```bash
./setup.sh
./run.sh
```

`setup.sh` выбирает CUDA, ROCm или CPU по доступному оборудованию. На Fedora
для запуска через `run.sh` нужен Qt/X11 backend `xcb`.

### Windows 11 preview

Подготовлены исходники и упаковка для Python 3.11 x64 и CPU-транскрипции:

```powershell
.\setup-windows.ps1
.\run-windows.ps1
```

Для преобразования и видеовозможностей `ffmpeg` и `ffprobe` должны быть в
`PATH`. В `packaging/windows/` подготовлен конвейер PyInstaller/ZIP/installer,
но Windows остаётся preview до завершения проверок на оборудовании, чистой VM
и release gate из `docs/WINDOWS_SUPPORT_PLAN.ru.md`.

### Диаризация

```bash
.venv/bin/pip install "pyannote.audio>=3.1" "torch>=2.0"
.venv/bin/python setup_diarization.py
```

Понадобится read-токен Hugging Face и принятые условия моделей
`pyannote/speaker-diarization-3.1` и `pyannote/segmentation-3.0`.

### LM Studio

1. Установите [LM Studio](https://lmstudio.ai).
2. Загрузите совместимую chat-модель.
3. Запустите локальный сервер, обычно на `http://localhost:1234/v1`.
4. При необходимости измените URL в настройках Whispered.

Без LM Studio продолжают работать транскрипция, диаризация, история,
редактирование, экспорт и монтаж.

## Сборка

macOS-приложение:

```bash
.venv/bin/pip install pyinstaller
.venv/bin/python build.py
```

`build.py` создаёт `dist/Whispered.app`. В dev-сборке нативный whisper-стек и
модели не встраиваются в `.app`: они размещаются отдельно, поэтому их можно
обновлять без пересборки приложения. Для самодостаточной сборки, которую можно
передать другому человеку, добавьте `--bundle-libs` (именно так собирает
релизный workflow):

```bash
.venv/bin/python build.py --bundle-libs --no-libs
```

Релизы по тегам собирает ручной workflow **Release**
(`.github/workflows/release.yml`) — запускается со вкладки Actions с вводом
`version`; он собирает macOS и Windows, прикладывает обе сборки и
`SHA256SUMS.txt` и оставляет черновик релиза на проверку. Заметки к релизам —
в `docs/release-notes/` (`TEMPLATE.md` для новых версий).

В репозитории также есть `appimage/build-appimage.sh`, но Linux AppImage пока не
является проверенным релизным каналом для всего текущего функционала.

Для Windows подготовлена unsigned preview-сборка:

```powershell
.\packaging\windows\build-windows.ps1
```

Она создаёт `onedir`-пакет и ZIP. Inno Setup installer и code signing остаются
частью release gate; подробности — в `packaging/windows/README.md`.

## Разработка и проверка

```bash
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
.venv/bin/ruff check .
.venv/bin/python -m pytest tests/ -q
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest tests_qt/ -q
QT_QPA_PLATFORM=offscreen .venv/bin/python tools/render_ui_gallery.py --check
```

Unit-набор (`tests/`, на заглушках PyQt6) и отдельный offscreen-Qt smoke-набор
(`tests_qt/`, настоящий Qt) проходят. CI запускает тесты и блокирующий `ruff`
на Linux (Python 3.11) и на каждый push собирает unsigned Windows-пакет с
frozen smoke-тестом. `mypy` блокирующий для набора модулей из
[CLAUDE.md](CLAUDE.md) и информационный для `ui/`.

Код разбит на слои: `domain/` (DTO без Qt), `application/` (движок заданий,
реестр шагов, контроллер экспорта), `infrastructure/` (манифесты артефактов),
`core/` (воркеры, история, LLM-клиенты), `ui/` — карта архитектуры в

## Известные ограничения

- Для Windows подготовлены исходники, упаковка и CI-preview, но платформа ещё
  не прошла валидацию для релиза: остаются проверки на реальном оборудовании,
  в чистой VM и code-signing gate.
- Диаризация требует отдельных тяжёлых зависимостей, Hugging Face-токена и
  принятия условий моделей. Подсказки имён спикеров — не автоматическое
  распознавание.
- Локальные обращения к LM Studio сериализуются на уровне процесса. Длинная
  генерация всё ещё может задержать отмену, пока читается текущий HTTP-ответ.
- В AI-запросы передаётся не более настроенного лимита контекста; для длинных
  записей главы и инсайты равномерно семплируются по всей записи.
- Облачный провайдер применяется только к YouTube-пакету.
- Файлы из очереди (папка, перетаскивание нескольких файлов, watch-папка)
  только расшифровываются и сохраняются в историю; шаги рецепта к каждому файлу
  не запускаются.
- Поиск плиток Zoom, ONNX-реставрация и ComfyUI для обложек не подключены к UI.
  Слияние транскриптов Zoom multitrack (отдельные дорожки участников) есть
  только в виде модулей движка без точки входа в интерфейсе.
- Захват системного аудио для Live и Course Capture работает только на macOS и
  остаётся экспериментальным.
