**Локальная транскрипция аудио и видео с инструментами для дальнейшей работы
с материалом.**

Whispered — настольное приложение на PyQt6. Оно транскрибирует записи через
`whisper.cpp`, при необходимости размечает спикеров через `pyannote.audio`,
хранит историю и помогает превратить транскрипт в субтитры, статьи,
YouTube-пакет, инсайты, книжный черновик или монтажный таймлайн.

Транскрипция выполняется локально. AI-функции по умолчанию используют локальный
сервер LM Studio. Отправка текста во внешний сервис происходит только при
явном выборе облачного провайдера на вкладке YouTube.

## Загрузка

Готовые сборки публикуются на странице
[**Releases**](https://github.com/samoilovda/Whispered/releases/latest):

| Платформа | Файл |
|---|---|
| macOS (Apple Silicon, 13+) | `Whispered-<версия>-macos-arm64.zip` |
| Windows 11 (x64) | `Whispered-<версия>-windows-x64.zip` |

Обе сборки пока **без подписи**. На macOS при первом запуске — правый клик по
`Whispered.app` → **Открыть** (или `xattr -dr com.apple.quarantine
/Applications/Whispered.app`); на Windows в SmartScreen — **Подробнее** →
**Выполнить в любом случае**. В заметках к каждому релизу это описано на
русском и английском, а `SHA256SUMS.txt` позволяет проверить загрузку.
Сборка macOS содержит движок whisper внутри — отдельная установка не нужна.

Сборку из исходников см. в разделе [Сборка](#сборка).

## Интерфейс

Окно приложения — это двухколоночное рабочее пространство: слева
сворачиваемая (в том числе автоматически на узких окнах) панель Библиотеки,
справа текущий документ — стартовый экран, карточка записи, обложки или
экран прогона, в зависимости от задачи. Расположение панелей запоминается
между запусками.

- Стартовый экран выбирает источник (файл, папка, микрофон или Live) и
  рецепт — один из пяти встроенных наборов шагов (только расшифровка, видео
  на YouTube, статья из подкаста, заметки со встречи, книга) или
  пользовательский, настраиваемый через «Настроить…» — и запускается одной
  кнопкой; параметры прогона спрятаны за одной строкой сводки и ссылкой
  «Изменить».
- Запуск выполняет рецепт как один прогон на экране прогона: по одной строке
  на шаг (расшифровка, очистка, статья, инсайты, YouTube-пакет, книга,
  обложка), живой прогресс, точечный перезапуск/отмена без повторной
  расшифровки уже сделанного. После завершения расшифровки её генераторы —
  Статьи, YouTube, Книга, Инсайты, Cut, Chat — становятся вкладками карточки
  записи.
- `Ctrl+K` открывает командную палитру: поиск по истории транскриптов, все
  рецепты («Запустить: <рецепт>») и провалившиеся/отменённые шаги открытого
  прогона («Перезапустить: <шаг>»), а также быстрые действия (новая запись,
  YouTube-пакет, экспорт, Live, очередь, настройки).
- Карточка записи в Библиотеке сразу показывает провалившиеся шаги прогона,
  не открывая запись, и фильтруется по рецепту вместе с существующим
  фильтром по источнику.
- Единый статус-бар внизу показывает текущую операцию, прогресс, отмену,
  всплывающую очередь пакетных задач и статус LM Studio/GPU.

## Что умеет приложение

### Генератор обложек

Раздел **«Обложки»** открывается из Библиотеки и создаёт YouTube-обложки
«Просвета» по декларативному шаблону. Доступны раскладки для двух участников,
одного участника и только текста, мятный/тёплый варианты, живое превью, ручные
портреты, подсказка заголовка из открытого транскрипта и воспроизводимый
экспорт PNG/JPEG с `.cover.json`. Исходный Templegarten заменён на встроенный
Bellota Bold с лицензией OFL и системным фолбэком. Экспорт Shorts остаётся
опцией до бренд-приёмки авторской адаптации 9:16.

Извлечение кадров, поиск плиток Zoom, ONNX-реставрация и localhost-адаптер
ComfyUI пока существуют как экспериментальные модули ядра и не подключены к
рабочему пространству Cover. Портреты выбираются из файлов PNG/JPEG.

### Транскрипция

- аудио: MP3, WAV, FLAC, M4A, OGG, OPUS, WMA, AAC;
- видео: MP4, MKV, AVI, MOV, WebM, WMV, FLV, M4V;
- модели Whisper: Tiny, Base, Small, Medium, Large v3 и варианты Turbo;
- автоопределение языка, выбор одного из 19 языков и перевод речи на английский;
- режимы производительности и ускорение CPU / Metal / CUDA / ROCm;
- пользовательский словарь, передаваемый Whisper как initial prompt;
- реальная отмена транскрипции: движок запускается в отдельном процессе,
  который можно завершить, не закрывая приложение.

Для преобразования медиафайлов, определения длительности и видеомонтажа нужны
`ffmpeg` и `ffprobe`.

### Спикеры

Опциональная диаризация через `pyannote.audio` добавляет метки спикеров.
В интерфейсе можно переименовывать и объединять спикеров; имена сохраняются в
истории и используются при экспорте.

### Библиотека, очередь и запись

- SQLite-история транскрипций с полнотекстовым поиском FTS5 и запасным поиском
  через `LIKE`;
- повторное открытие сохранённого транскрипта, его сегментов, метаданных и имён
  спикеров;
- последовательная пакетная обработка нескольких файлов;
- запись с микрофона с выбором устройства, индикатором уровня, паузой и
  продолжением записи;
- drag-and-drop файлов и интерфейс на русском или английском языке.

История хранит транскрипты, но не восстанавливает содержимое ранее
сгенерированных AI-материалов. Результаты рецепта сохраняются отдельными
файлами в каталоге данных приложения.

### Работа с транскриптом

- встроенный аудио/видеоплеер и переход к позиции по клику на сегмент;
- редактирование сегментов с сохранением тайм-кодов;
- поиск, замена, копирование и переименование спикеров;
- экспорт в 9 форматов: TXT, TXT с тайм-кодами,
  SRT, VTT, JSON, Markdown, HTML, DOCX и PDF.

### AI-инструменты

Для следующих функций нужен запущенный LM Studio с загруженной chat-моделью:

- очистка текста от слов-паразитов и приведение устной речи к связному тексту;
- пять форматов материалов: блог-пост, FAQ, листикл, краткое резюме и посты
  для соцсетей;
- чат с контекстом открытого транскрипта и потоковой выдачей ответа;
- инсайты: главы, задачи и ключевые моменты;
- книжный конвейер: «расшивка» устной речи, дополнительный пользовательский
  промпт и пакетная обработка Markdown-файлов.

YouTube-пакет включает:

- главы с тайм-кодами;
- варианты заголовков;
- описание;
- теги;
- ключевые вопросы с тайм-кодами.

Только YouTube-пакет можно генерировать не только через LM Studio, но и через
OpenAI-совместимый API или Anthropic с ключом пользователя. Остальные
AI-инструменты сейчас работают через LM Studio.

### Хранение API-ключей

Если установлен необязательный пакет `keyring` и доступен рабочий backend ОС,
API-ключи облачных провайдеров и токен Hugging Face сохраняются в macOS
Keychain, Windows Credential Manager или Linux Secret Service. Иначе
Whispered использует локальный конфигурационный файл с доступом только для
владельца. Используйте отдельный ключ с минимально необходимыми правами.

### Рецепты

Транскрипция и сохранение в историю выполняются всегда. Дальше выбранный
рецепт выполняет свои оставшиеся шаги — любую комбинацию очистки, статьи,
инсайтов, YouTube-пакета, книги и обложки — как один прогон (лимиты
параллелизма по ресурсу, пропуск по кешу при неизменных модели/промпте/
транскрипте, точечный перезапуск). Пять встроенных рецептов покрывают
типичные случаи; «Настроить…» открывает пошаговый редактор для разовой
комбинации, сохраняемой как один пользовательский рецепт. Монтажные операции
запускаются вручную.

### Монтаж

На вкладке Cut можно выбрать сохраняемые сегменты, автоматически снять выбор с
пауз, перейти к нужному месту в плеере, экспортировать CMX3600 EDL и собрать
черновой MP4 через `ffmpeg`. Сборка MP4 по умолчанию перекодирует выбранные
фрагменты для более точных границ.

### Live-транскрипция

Экспериментальный Live-раздел включается вручную в настройках, а запускается
из выбора источника (файл / папка / запись с микрофона / Live) при создании
новой записи. Реализованы:

- микрофонный и системный источники;
- асинхронная предварительная проверка готовности;
- инкрементальный транскрипт, пауза/продолжение и диагностика;
- сохранение финальных текстовых сегментов в библиотеку во время сессии;
- обнаружение приложений и захват системного аудио через отдельный
  ScreenCaptureKit-helper.

Live не пишет WAV, M4A или временный PCM-файл: аудио существует только в
ограниченных буферах памяти, нужных для текущего распознавания. Поэтому
в библиотеке у такой сессии доступен текст и экспорт, но нет плеера и
операций, которым нужен исходный медиафайл.

Захват системного аудио доступен только на macOS 13+ и требует собранного
Swift-helper, а также разрешения Screen Recording. Live остаётся
экспериментальной, выключенной по умолчанию функцией и ещё не прошёл полный
релизный soak-тест.

## Быстрый старт

Требования:

- CPython 3.11;
- `ffmpeg` и `ffprobe`;
- macOS (основная платформа), Linux или Windows 11 x64 в preview-режиме;
- LM Studio — только для AI-функций.

### macOS

```bash
./setup-mac.sh
./run-mac.sh
```

Скрипт `setup-mac.sh` создаёт окружение, собирает `pywhispercpp` с Metal на
Apple Silicon и устанавливает все объявленные runtime-зависимости. Нужную
модель Whispered загружает при первом использовании.

### Linux

```bash
./setup.sh
./run.sh
```

`setup.sh` выбирает CUDA, ROCm или CPU по доступному оборудованию. На Fedora
для запуска через `run.sh` нужен Qt/X11 backend `xcb`.

### Windows 11 preview

Подготовлены исходники и упаковка для Python 3.11 x64 и CPU-транскрипции:

```powershell
.\setup-windows.ps1
.\run-windows.ps1
```

Для преобразования и видеовозможностей `ffmpeg` и `ffprobe` должны быть в
`PATH`. В `packaging/windows/` подготовлен конвейер PyInstaller/ZIP/installer,
но Windows остаётся preview до завершения проверок на оборудовании, чистой VM
и release gate из `docs/WINDOWS_SUPPORT_PLAN.ru.md`.

### Диаризация

```bash
.venv/bin/pip install "pyannote.audio>=3.1" "torch>=2.0"
.venv/bin/python setup_diarization.py
```

Понадобится read-токен Hugging Face и принятые условия моделей
`pyannote/speaker-diarization-3.1` и `pyannote/segmentation-3.0`.

### LM Studio

1. Установите [LM Studio](https://lmstudio.ai).
2. Загрузите совместимую chat-модель.
3. Запустите локальный сервер, обычно на `http://localhost:1234/v1`.
4. При необходимости измените URL в настройках Whispered.

Без LM Studio продолжают работать транскрипция, диаризация, история,
редактирование, экспорт и монтаж.

## Сборка

macOS-приложение:

```bash
.venv/bin/pip install pyinstaller
.venv/bin/python build.py
```

`build.py` создаёт `dist/Whispered.app`. В dev-сборке нативный whisper-стек и
модели не встраиваются в `.app`: они размещаются отдельно, поэтому их можно
обновлять без пересборки приложения. Для самодостаточной сборки, которую можно
передать другому человеку, добавьте `--bundle-libs` (именно так собирает
релизный workflow):

```bash
.venv/bin/python build.py --bundle-libs --no-libs
```

Релизы по тегам собирает ручной workflow **Release**
(`.github/workflows/release.yml`) — запускается со вкладки Actions с вводом
`version`; он собирает macOS и Windows, прикладывает обе сборки и
`SHA256SUMS.txt` и оставляет черновик релиза на проверку. Заметки к релизам —
в `docs/release-notes/` (`TEMPLATE.md` для новых версий).

В репозитории также есть `appimage/build-appimage.sh`, но Linux AppImage пока не
является проверенным релизным каналом для всего текущего функционала.

Для Windows подготовлена unsigned preview-сборка:

```powershell
.\packaging\windows\build-windows.ps1
```

Она создаёт `onedir`-пакет и ZIP. Inno Setup installer и code signing остаются
частью release gate; подробности — в `packaging/windows/README.md`.

## Разработка и проверка

```bash
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
.venv/bin/ruff check .
.venv/bin/python -m pytest tests/ -q
QT_QPA_PLATFORM=offscreen .venv/bin/python tools/render_ui_gallery.py --check
```

Текущий unit-набор и отдельный offscreen-Qt smoke-набор в `tests_qt/`
проходят. CI запускает тесты и блокирующий `ruff` на Linux (Python 3.11) и на
каждый push собирает unsigned
Windows-пакет с frozen smoke-тестом на Python 3.11. `mypy` блокирующий для
набора модулей из [CLAUDE.md](CLAUDE.md) и информационный для `ui/`.

Основные шаблоны AI-задач находятся в 17 Markdown-файлах каталога `prompts/`.
Для отказоустойчивости часть модулей также содержит встроенные fallback-тексты.

Подробнее: [TESTING.md](TESTING.md), [ROADMAP.md](ROADMAP.md) и
[CLAUDE.md](CLAUDE.md).

## Известные ограничения

- Для Windows подготовлены исходники, упаковка и CI-preview, но платформа ещё
  не прошла валидацию для релиза: остаются проверки на реальном оборудовании,
  в чистой VM и code-signing gate.
- Диаризация требует отдельных тяжёлых зависимостей, Hugging Face-токена и
  принятия условий моделей.
- Локальные обращения к LM Studio сериализуются на уровне процесса. Длинная
  генерация всё ещё может задержать отмену, пока читается текущий HTTP-ответ.
- В AI-запросы передаётся не более настроенного лимита контекста; для длинных
  записей главы и инсайты равномерно семплируются по всей записи.
- Облачный провайдер применяется только к YouTube-пакету.
- Модули обработки портретов Cover пока не подключены к UI; поддерживаемый
  путь — ручной выбор PNG/JPEG.
- Live-захват системного аудио работает только на macOS и остаётся
  экспериментальным.
