**Privacy-first desktop studio that turns audio and video into publishable
content — fully offline.** Drop in an hour-long interview and get back a
transcript with speaker labels, a ready-to-paste YouTube package (titles,
description, tags, chapter timecodes), and article drafts — without a single
byte leaving your machine.

## Why

Cloud transcription services are subscription-priced, upload your raw
recordings to someone else's servers, and rate-limit long files. Whispered
runs the entire pipeline locally: `whisper.cpp` for speech-to-text (Metal /
CUDA / ROCm accelerated), `pyannote.audio` for speaker diarization, and any
local LLM served by LM Studio for content generation. Your data stays yours.

## Features

- **Transcription** — `whisper.cpp` with hardware acceleration, model picker
  (tiny → large-v3-turbo), 99 languages, translation to English, custom
  vocabulary hints.
- **Speaker diarization** — who-said-what labels via `pyannote.audio`, with
  speaker renaming.
- **One-click presets** — *Transcribe*, *+ YouTube package*, *+ Article*,
  *Full*: pick a file, press Process, collect the artifacts.
- **YouTube package** — 5 title options, a hook + summary description,
  chapter timecodes (viewer-oriented, max 7.5-minute gaps), key-question
  timecodes, and tags — generated by a local LLM from the full transcript.
- **Content generation** — article drafts in 5 formats (blog post, FAQ,
  listicle, summary, social posts), transcript cleanup, AI chat with the
  transcript, insights (chapters / action items / key moments).
- **Library** — every transcription auto-saved with full-text search
  (SQLite FTS5); reopen any recording with its artifacts.
- **Recorder & batch queue** — record from the microphone, or queue a folder
  of files.
- **Cut tab** — tick/untick segments and export an EDL timeline for video
  editors.
- **Export** — TXT, TXT+timestamps, SRT, VTT, JSON, Markdown, HTML, DOCX, PDF.
- **UI** — dark/light themes, RU/EN localization, drag-and-drop.

The only optional network calls: model downloads you explicitly request, and
a user-supplied cloud API key for one YouTube-tab feature (off by default —
the local LLM path is the default).

## How it works

```
media file ──▶ ffmpeg ──▶ whisper.cpp (separate process, cancellable)
                             │
                             ▼
                        transcript + speakers (pyannote)
                             │
                             ▼
                 local LLM via LM Studio (OpenAI-compatible API)
                             │
                             ▼
        YouTube package · articles · insights · cleaned text
```

| Layer | Modules |
|---|---|
| UI (PyQt6) | `ui/` — main window, library, launch bar, result tabs |
| Workers | `core/` — QThread workers, LM Studio client, history store, i18n |
| Engines | `transcriber.py`, `diarizer.py`, `article_generator.py`, `text_processor.py` |
| Prompts | `prompts/*.md` — every LLM task is an editable Markdown prompt |

Transcription runs in a separate **process** (hard cancellation, no GIL
contention); all LLM/IO work runs in **QThreads** — the UI never blocks.

## Quick start

**Fedora / Linux**

```bash
./setup.sh   # installs deps, compiles whisper.cpp, downloads the default model
./run.sh
```

**macOS**

```bash
./setup-mac.sh
./run-mac.sh
```

A standalone `Whispered.app` can be built with `.venv/bin/python build.py`;
an AppImage with `appimage/build-appimage.sh`.

For AI features, install [LM Studio](https://lmstudio.ai), load any chat
model and start the local server (`lms server start`) — Whispered picks it up
automatically. Everything else (transcription, diarization, export) works
without it. Windows is not supported yet — see the [roadmap](ROADMAP.md).

## Development

```bash
pip install -r requirements.txt -r requirements-dev.txt
ruff check .                 # lint — must be clean
python -m pytest tests/ -q   # 292 unit tests, Qt fully stubbed
python main.py               # run from source
```

See [TESTING.md](TESTING.md) for test conventions and
[CLAUDE.md](CLAUDE.md) for the project rules that both humans and AI agents
follow.

This project is developed AI-first: the code is written in collaboration
with AI coding agents against self-contained specs (see `docs/archive/` for
the executed plans), with a hard gate of lint + tests + a headless UI smoke
check before every commit.
